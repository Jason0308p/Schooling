## 整合 Google Ads 與 GA4：ROAS 儀表板

廣告成效儀表板的核心挑戰是：**廣告費用數據在 Google Ads，網站轉換數據在 GA4，兩者需要整合才能計算 ROAS**。這堂課帶你完成完整的整合流程，並建立 ROAS、CTR、CPC 計算欄位。

> [!BIZ] 為什麼要做廣告成效儀表板？
> 廣告投放人員每天需要回答：「這個廣告活動值得繼續投放嗎？」要回答這個問題，需要同時看到花了多少錢（Ads 數據）和帶來多少轉換與營收（GA4 數據）。如果每次都要分別開 Ads 後台和 GA4 後台再手動比對，很難快速做出決策。

---

## Step 1：連接 Google Ads 資料來源

### 前置條件

- 需要對 Google Ads 帳號有**唯讀（Read-only）以上**的存取權限
- 使用與 Looker Studio 相同的 Google 帳號，或請 Ads 帳號管理員授權存取

### 連接步驟

1. 首頁「建立 → 資料來源」，選 Google Ads 連接器並授權；也可從報表新增來源。
2. 選 ALL ACCOUNTS 與目標帳戶；管理員帳戶選 MANAGER ACCOUNTS 及有權存取的子帳戶。
3. 選 **Overall Account Fields** → CONNECT，再新增至報表。不是在連接器選 Campaign 層級；粒度在圖表／混合表用維度設定。
4. 常用 Ads 欄位有 Cost（帳戶幣別）、Clicks、Impressions、Conversions。GA4 則用 Key events；關鍵事件可用來建立 Ads 轉換，但不是自動等同 Ads Conversions，須確認轉換動作、歸因及計數方式，不概括指定以 GA4 為準。

### 資料 freshness

Data freshness 是查詢快取門檻，不代表平台已完成處理。Ads 等廣告產品的官方門檻為 12 小時；GA4 同頁表列 1／4／12 小時、預設 12 小時，但概述又稱 Google 產品固定 12 小時，須以實際來源設定核對。快取、來源處理延遲與轉換回補是不同問題，不應說費用固定延遲 1–3 天或保證即時更新。

## Step 2：建立 Blended Data

1. 「資源 → 管理混合資料 → 新增混合」。
2. **左表 Google Ads**：Date、帳戶 ID、Campaign ID；Cost、Clicks、Impressions。
3. **右表 GA4**：確認 Ads 連結、自動標記及欄位可用，加入 Date、Session Google Ads customer ID、Session Google Ads campaign ID；Sessions、Key events、Total revenue。先測試維度／指標相容性，介面語言可能影響欄名。
4. 兩側彙總至相同的「日期 × 帳戶 × 活動」粒度，每組鍵各一列；用對應日期、帳戶與活動穩定 ID 等值 Join，確認型別及格式。
5. **Left outer join，以 Ads 為左表**，保留沒有 GA4 配對的花費；不要在後續圖表以 GA4 非空條件濾掉未配對列。
6. 兩側日期採 Auto，儲存為「GA4 + Ads Blend」，用 Ads 左表日期及活動鍵顯示，核對混合前後 Cost 合計。

> [!WARN] 穩定鍵、粒度、幣別
> 活動名稱可能重複或改名，日期加名稱不保證唯一，自動標記也不保證 UTM 名稱相等。沒有共同 ID 時先建經驗證的對照表。任一側加裝置等維度都可能變成一對多／多對多，重複加總，必要時先在上游彙總。對齊時區、日期範圍、歸因與營收定義；Cost 與營收須同幣別，只改格式不會換匯。跨帳戶先依明確匯率政策上游換算；MCC 的 All currencies 有自動換算規則，先查輸出幣別避免二次換匯。

未配對的營收保留 NULL 並標記資料品質，不直接視為零成效；只有確認追蹤完整且確無營收時才按規則補零。本課 GA4 工作階段歸屬活動營收除以 Ads 花費，不保證等於 Ads 歸因 ROAS。

## Step 3：建立 ROAS、CTR、CPC 計算欄位

計算欄位讓你用公式把現有欄位組合成新的指標。

### 先 Blend，再建立圖表專屬計算欄位

1. 插入 Table 或 Scorecard，資料來源選「GA4 + Ads Blend」。
2. 在圖表 Setup 選「新增指標 → 建立欄位」，建立 **chart-specific calculated field**。
3. 混合編輯器的單表計算欄位只能引用該表；跨來源必須先將欄位加入各自混合表，再在圖表算 ROAS。
4. 下列 Revenue 是 GA4 Total revenue 在混合後的別名，請從選擇器插入實際欄位。公式用於混合後可重新彙總的指標；原生來源 Auto 指標不可直接再套 SUM。
5. 用總量相除，不平均逐列比率。圖表專屬欄位不會自動共用至其他圖表，需各自建立或複製圖表。

### ROAS 計算欄位

- **欄位名稱**：`ROAS`
- **公式**：
  ```
  SUM(Revenue) / NULLIF(SUM(Cost), 0)
  ```
- **格式**：數字，小數位 2，可加上「x」後綴讓顯示更直觀（如 5.2x）

### CTR（點擊率）計算欄位

- **欄位名稱**：`CTR`
- **公式**：
  ```
  SUM(Clicks) / NULLIF(SUM(Impressions), 0)
  ```
- **格式**：百分比，小數位 2

### CPC（每次點擊費用）計算欄位

- **欄位名稱**：`CPC`
- **公式**：
  ```
  SUM(Cost) / NULLIF(SUM(Clicks), 0)
  ```
- **格式**：幣別，小數位 2

> [!TIP] 實務建議
> 所有除法公式都要加 `NULLIF(分母, 0)`，避免當某個廣告活動沒有點擊（Clicks = 0）時，Looker Studio 顯示錯誤或無限大。`NULLIF(x, 0)` 的意思是：如果 x = 0，就回傳 NULL（空值），NULL 除以任何數都是 NULL，而不是錯誤。

## Step 4：建立廣告成效儀表板版面

### 頂部 Scorecard 列（使用 Blended Data）

1. 插入 4 個 Scorecard，資料來源選「GA4 + Ads Blend」
2. 依序設定指標：**ROAS**、**Cost**、**GA4 Key events**、**CPC**
3. 所有 Scorecard 開啟「比較日期範圍」→ 上一個時段

### 廣告活動績效表（Table with Heatmap）

1. 插入 Table，資料來源選「GA4 + Ads Blend」
2. **列維度**：`Campaign name`
3. **指標**：Cost、Clicks、CTR、GA4 Key events、Revenue、ROAS
4. 在 Style 將「ROAS」數值欄位的 Column type 設為 Heatmap（ROAS 越高背景越深）
5. 排序：ROAS DESC

> [!BIZ] 為什麼要按 ROAS 排序？
> 按 ROAS 排序讓廣告投放人員立刻看到「哪個活動最有效率」。一個花費少但 ROAS 高的活動，可能值得增加預算；一個花費高但 ROAS 低的活動，則需要暫停或調整。這個表格直接支援廣告預算分配決策，是廣告儀表板最高價值的區塊。


> [!TIP] 驗收
> 同時檢查高花費低成效及未配對活動，不只依 ROAS 排名。日期控制項可跨來源，確認有效日期維度、Auto、自訂日期覆寫與群組範圍。
