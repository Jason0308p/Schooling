## Table with Heatmap、Pivot Table、Blended Data

當你需要深入分析多維度數據，或整合來自不同平台的資料時，這三個進階元件是關鍵工具。

> [!BIZ] 為什麼需要這些進階元件？
> Scorecard 和折線圖適合呈現整體趨勢，但行銷人員更常需要回答「哪個廣告活動在哪個裝置上轉換最好？」這類多維度問題——這就需要 Table with Heatmap 和 Pivot Table。而 Blended Data 讓你不需要依賴工程師，自己就能合併 GA4 與廣告平台的數據。

---

## Table with Heatmap（帶熱力圖的表格）

### 適用場景

- 呈現多列多欄的明細數據，同時用顏色快速識別高低值
- 廣告活動績效對比表（多個活動 × 多個指標）
- 登陸頁轉換率排名

### 設定步驟

1. 點選「插入（Insert）」→「表格（Table）」
2. 在「設定（Setup）」分頁：
   - **列維度（Row dimension）**：選擇分組依據，例如「Landing page」或「Campaign name」
   - **指標（Metric）**：加入多個指標，例如「Sessions」、「Conversions」、「Conversion rate」
3. 切換到「**樣式（Style）**」分頁
4. 在指標欄位清單中，找到要加 Heatmap 的欄位，勾選「**Show heatmap**」
5. 可以調整 Heatmap 的顏色（預設白→藍，也可以改成白→綠或白→橘）

> [!TIP] 實務建議
> 建議只對 1–2 個最重要的指標開啟 Heatmap（例如轉換率、ROAS），避免整張表都是深色，反而失去對比效果。排名指標（如 Sessions）通常不需要 Heatmap，因為已有排序功能。

### 條件式格式化（進階）

除了 Heatmap，Looker Studio 也支援「條件式格式化（Conditional formatting）」，可以設定：
- 數值大於某個閾值時，該格顯示紅色底色
- 例如：Bounce rate > 70% → 紅色；Bounce rate < 40% → 綠色

設定路徑：樣式分頁 → 指標欄位 → 「條件式格式化」→ 設定規則

## Pivot Table（樞紐分析表）

### 適用場景

- **雙維度交叉分析**：例如「流量來源 × 裝置類型」的 Sessions 分布
- 比較廣告活動在不同地區或時間段的表現
- 找出哪個維度組合有最高的轉換率

### 設定步驟

1. 點選「插入」→「樞紐分析表（Pivot table）」
2. 在「設定」分頁：
   - **列維度（Row dimension）**：放在表格左側的分組，例如「Session source / medium」
   - **欄維度（Column dimension）**：放在表格頂部的分組，例如「Device category」
   - **指標（Metric）**：交叉格子裡的數值，例如「Sessions」或「Conversions」
3. 可以同時加入多個列維度（系統會建立階層式分組）
4. 勾選「顯示合計（Show totals）」可在最後一列/欄顯示加總

> [!WARN] 常見問題
> Pivot Table 的欄維度如果類別很多（例如 30 個城市），表格會變得非常寬而難以閱讀。建議先在資料層面加篩選器，只保留前幾個最重要的類別，或改用 Table + 排序的方式呈現。

## Blended Data（資料混合）

### 什麼是 Blended Data？

Blended Data 允許你在**同一個圖表**中合併來自不同資料來源的數據，類似 SQL 的 JOIN 操作，但不需要寫程式。

**常見使用情境：**
- 合併 GA4（網站行為）+ Google Ads（廣告費用）→ 計算 ROAS
- 合併 Google Search Console（搜尋排名）+ GA4（流量）→ 分析 SEO 成效
- 合併 Google Sheets（目標值）+ GA4（實際值）→ 目標達成率儀表板

### 設定步驟

1. 在編輯模式下，點選上方工具列「**資源（Resource）**」→「**管理混合的資料來源（Manage blended data）**」
2. 點選「**新增資料混合（Add a data view）**」
3. 在左側「**資料來源 1**」面板：
   - 選擇第一個資料來源（例如：GA4）
   - 選擇要加入的維度，例如「Date」、「Campaign name」
   - 選擇要加入的指標，例如「Sessions」、「Conversions」
4. 點選右側「**新增另一個資料來源（Add another data source）**」：
   - 選擇第二個資料來源（例如：Google Ads）
   - 選擇維度，例如「Date」、「Campaign name」
   - 選擇指標，例如「Cost」、「Clicks」
5. 設定 **Join Key（連接鍵）**：
   - 點選兩個資料來源之間的「**連接（Join）**」區域
   - 選擇用於匹配的欄位，通常是「Date」+「Campaign name」
   - 確認 Join 類型（預設為 Left outer join，保留第一個來源的所有資料）
6. 點選「**儲存（Save）**」，Blended Data 就會出現在資料來源清單中

### 在圖表中使用 Blended Data

1. 插入新圖表（例如 Table）
2. 在「設定」分頁的資料來源下拉選單，選擇剛建立的 Blended Data
3. 現在你可以同時使用兩個資料來源的維度和指標

> [!WARN] 常見問題
> 如果 Join 後數據不正確（例如 Sessions 突然變很大），通常是 Join Key 設定錯誤導致**笛卡爾積（Cartesian product）**——一個 GA4 的 row 對應到多個 Ads 的 row，數值被重複加總。解決方法：檢查 Join Key 是否足夠精確（加入 Campaign name 讓日期不會重複對應）。

> [!TIP] 實務建議
> Blended Data 的處理是在 Looker Studio 端完成，不需要 BigQuery 或 SQL。但如果資料量很大（數百萬 row），建議改用 BigQuery 做 JOIN 後再連接到 Looker Studio，效能會更好。
