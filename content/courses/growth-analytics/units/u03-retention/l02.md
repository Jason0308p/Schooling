## Rolling 與 Bracket：先固定人群與截止日

Rolling DN 是第 N 個日曆日**或之後**曾回訪，並非第 1–N 天（後者是 bracket）。本課固定 2025-01-01 至 2025-06-30 註冊 cohort、觀察截止 2025-07-31（含整天），每位用戶至少有 D30 觀察期。date() 定義日曆日，非連續 24 小時。

## 固定 cohort 的 Rolling D7 / D30

Rolling 是第 N 日或之後；固定 cohort、共同截止日之下 D30 ≤ D7。日期先 date() 正規化為日曆日，截止日含整天。不可把不同成熟度或不同 cohort 的百分比當同一條曲線。

```sql run
WITH flags AS (
 SELECT u.user_id,
 MAX(CASE WHEN date(da.log_date) >= date(u.signup_date, '+7 days') THEN 1 ELSE 0 END) AS d7,
 MAX(CASE WHEN date(da.log_date) >= date(u.signup_date, '+30 days') THEN 1 ELSE 0 END) AS d30
 FROM users u LEFT JOIN daily_active da ON da.user_id=u.user_id AND date(da.log_date) <= '2025-07-31'
 WHERE date(u.signup_date) >= '2025-01-01' AND date(u.signup_date) < '2025-07-01'
 GROUP BY u.user_id
)
SELECT COUNT(*) AS total_users, COALESCE(SUM(d7),0) AS rolling_d7_retained,
 ROUND(SUM(d7)*100.0/NULLIF(COUNT(*),0),2) AS rolling_d7_pct,
 COALESCE(SUM(d30),0) AS rolling_d30_retained,
 ROUND(SUM(d30)*100.0/NULLIF(COUNT(*),0),2) AS rolling_d30_pct FROM flags;
```

## Cohort 月留存表（W1 / W2 / W4）

Bracket 各週分開計算，不是存活曲線；W1 − W4 是百分點差，可以為負。不足以證明流失、因果或方案優劣。共同 cohort 與截止日讓觀察期一致。

```sql run
WITH flags AS (
  SELECT
    strftime('%Y-%m', u.signup_date) AS cohort_month,
    u.user_id,
    MAX(CASE WHEN julianday(date(da.log_date))-julianday(date(u.signup_date)) BETWEEN 1  AND 7  THEN 1 ELSE 0 END) AS w1,
    MAX(CASE WHEN julianday(date(da.log_date))-julianday(date(u.signup_date)) BETWEEN 8  AND 14 THEN 1 ELSE 0 END) AS w2,
    MAX(CASE WHEN julianday(date(da.log_date))-julianday(date(u.signup_date)) BETWEEN 22 AND 28 THEN 1 ELSE 0 END) AS w4
  FROM users u
  LEFT JOIN daily_active da ON da.user_id = u.user_id AND date(da.log_date) <= '2025-07-31'
  WHERE date(u.signup_date) >= '2025-01-01' AND date(u.signup_date) < '2025-07-01'
  GROUP BY u.user_id, cohort_month
)
SELECT
  cohort_month,
  COUNT(*)                              AS cohort_size,
  ROUND(SUM(w1) * 100.0 / COUNT(*), 1) AS w1_pct,
  ROUND(SUM(w2) * 100.0 / COUNT(*), 1) AS w2_pct,
  ROUND(SUM(w4) * 100.0 / COUNT(*), 1) AS w4_pct
FROM flags
GROUP BY cohort_month
ORDER BY cohort_month;
```

## 各方案的 W1 vs W4 留存差異

Bracket 各週分開計算，不是存活曲線；W1 − W4 是百分點差，可以為負。不足以證明流失、因果或方案優劣。共同 cohort 與截止日讓觀察期一致。

```sql run
WITH brackets AS (
  SELECT
    u.user_id,
    u.plan,
    MAX(CASE WHEN julianday(date(da.log_date))-julianday(date(u.signup_date)) BETWEEN 1  AND 7  THEN 1 ELSE 0 END) AS w1,
    MAX(CASE WHEN julianday(date(da.log_date))-julianday(date(u.signup_date)) BETWEEN 22 AND 28 THEN 1 ELSE 0 END) AS w4
  FROM users u
  LEFT JOIN daily_active da ON da.user_id = u.user_id AND date(da.log_date) <= '2025-07-31'
  WHERE date(u.signup_date) >= '2025-01-01' AND date(u.signup_date) < '2025-07-01'
  GROUP BY u.user_id, u.plan
)
SELECT
  plan,
  COUNT(*)                                                          AS total_users,
  ROUND(SUM(w1) * 100.0 / COUNT(*), 1)                             AS w1_pct,
  ROUND(SUM(w4) * 100.0 / COUNT(*), 1)                             AS w4_pct,
  ROUND((SUM(w1) - SUM(w4)) * 100.0 / COUNT(*), 1)                 AS drop_points
FROM brackets
GROUP BY plan
ORDER BY w4_pct DESC, plan ASC;
```

> [!WARN] 集合方向
> 同一 cohort、共同截止日下，Rolling D30 ⊆ Rolling D7，所以 D30 ≤ D7，N 增加只能持平或下降。延後截止日則是不同問題。Bracket W1 與 W4 不包含彼此，可升可降。

> [!DIALECT] 平台口徑
> Amplitude Return On or After 對應 rolling；Return On 是當日，Return On (Custom) 可定義區間。BigQuery 可用 DATE_DIFF 與 DATE 比較實作相同日曆日口徑。
