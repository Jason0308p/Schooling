## 留存定義：先確認人群、區間與資料覆蓋

精確 N-day 是恰第 N 日活躍；Rolling 是第 N 日或之後（有共同觀察截止日）；Bracket 是指定區間有活躍。本課 D7 的 6–8 日、D30 的 28–32 日是自訂容差 bracket，並非 N-day 的通用標準。1–7 日也只是第一週 bracket，不是 Rolling D7。

本課前三題沿用全體 users，早期註冊者可能缺少註冊後完整資料；只能解讀為資料中觀察到的回訪。下一課改固定完整 cohort 及截止日比較 rolling，避免混淆分母與成熟度。

## 計算整體 D7 容差區間 留存率

以每位用戶一次旗標計數、LEFT JOIN 保留未回訪者。D7 的 6–8 日與 D30 的 28–32 日是兩個不同 bracket，不互相包含，D30 可能高於 D7。這不是精確 N-day，不得據此宣稱因果或統計顯著差異。

```sql run
SELECT
  COUNT(DISTINCT u.user_id)                             AS total_users,
  COUNT(DISTINCT da.user_id)                            AS retained_d7,
  ROUND(COUNT(DISTINCT da.user_id) * 100.0
        / COUNT(DISTINCT u.user_id), 2)                 AS d7_retention_pct
FROM users u
LEFT JOIN daily_active da
  ON  da.user_id = u.user_id
  AND julianday(da.log_date) - julianday(u.signup_date) BETWEEN 6 AND 8;
```

## 同時計算 D7 容差區間 和 D30 容差區間 留存率

以每位用戶一次旗標計數、LEFT JOIN 保留未回訪者。D7 的 6–8 日與 D30 的 28–32 日是兩個不同 bracket，不互相包含，D30 可能高於 D7。這不是精確 N-day，不得據此宣稱因果或統計顯著差異。

```sql run
WITH flags AS (
  SELECT
    u.user_id,
    MAX(CASE WHEN julianday(da.log_date)-julianday(u.signup_date) BETWEEN 6  AND 8  THEN 1 ELSE 0 END) AS d7,
    MAX(CASE WHEN julianday(da.log_date)-julianday(u.signup_date) BETWEEN 28 AND 32 THEN 1 ELSE 0 END) AS d30
  FROM users u
  LEFT JOIN daily_active da ON da.user_id = u.user_id
  GROUP BY u.user_id
)
SELECT
  COUNT(*)                               AS total_users,
  ROUND(SUM(d7)  * 100.0 / COUNT(*), 2) AS d7_pct,
  ROUND(SUM(d30) * 100.0 / COUNT(*), 2) AS d30_pct
FROM flags;
```

## 各方案的 D30 容差區間 留存率比較

以每位用戶一次旗標計數、LEFT JOIN 保留未回訪者。D7 的 6–8 日與 D30 的 28–32 日是兩個不同 bracket，不互相包含，D30 可能高於 D7。這不是精確 N-day，不得據此宣稱因果或統計顯著差異。

```sql run
WITH flags AS (
  SELECT
    u.user_id,
    u.plan,
    MAX(CASE WHEN julianday(da.log_date)-julianday(u.signup_date) BETWEEN 28 AND 32
             THEN 1 ELSE 0 END) AS d30
  FROM users u
  LEFT JOIN daily_active da ON da.user_id = u.user_id
  GROUP BY u.user_id, u.plan
)
SELECT
  plan,
  COUNT(*)                               AS total_users,
  SUM(d30)                               AS retained_d30,
  ROUND(SUM(d30) * 100.0 / COUNT(*), 2) AS d30_pct
FROM flags
GROUP BY plan
ORDER BY d30_pct DESC;
```

## 真正的 Rolling D7 / D30

Rolling 是第 N 日或之後；固定 cohort、共同截止日之下 D30 ≤ D7。日期先 date() 正規化為日曆日，截止日含整天。不可把不同成熟度或不同 cohort 的百分比當同一條曲線。

```sql run
WITH flags AS (
 SELECT u.user_id,
 MAX(CASE WHEN date(da.log_date) >= date(u.signup_date, '+7 days') THEN 1 ELSE 0 END) AS d7,
 MAX(CASE WHEN date(da.log_date) >= date(u.signup_date, '+30 days') THEN 1 ELSE 0 END) AS d30
 FROM users u LEFT JOIN daily_active da ON da.user_id=u.user_id AND date(da.log_date) <= '2025-07-31'
 WHERE date(u.signup_date) >= '2025-01-01' AND date(u.signup_date) < '2025-07-01'
 GROUP BY u.user_id
)
SELECT COUNT(*) AS total_users, COALESCE(SUM(d7),0) AS rolling_d7_retained,
 ROUND(SUM(d7)*100.0/NULLIF(COUNT(*),0),2) AS rolling_d7_pct,
 COALESCE(SUM(d30),0) AS rolling_d30_retained,
 ROUND(SUM(d30)*100.0/NULLIF(COUNT(*),0),2) AS rolling_d30_pct FROM flags;
```

> [!WARN] 不同集合不可硬套大小關係
> 相同 cohort、相同截止日下精確 Day 7 包含於 Rolling D7；但 6–8 日容差包含 Day 6，並不保證小於 Rolling D7。Bracket D30 也不保證小於 Bracket D7。

> [!DIALECT] 平台口徑
> Amplitude Return On = 精確 N-day；Return On or After = Rolling；Return On (Custom) = 自訂 bracket。日曆日與 24 小時窗口須另行選定。
