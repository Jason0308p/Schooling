## 為什麼先問邊界

客服需要一串溫度的最高值；空陣列沒有最高溫，不能默默回傳 0。本例約定空輸入回傳 `null`，面試時應先與對方確認契約。

```js
function maximum(values) {
  if (values.length === 0) return null;
  let best = values[0];
  for (let i = 1; i < values.length; i++) {
    best = Math.max(best, values[i]);
  }
  return best;
}
```

## 手跑與不變量

`[-5,-2,-9]`：best 先是 -5，讀 -2 改成 -2，讀 -9 保持 -2。每次迭代後，best 是**已讀元素**的最大值。若初始化為 0，全負數時會錯誤回傳 0。

## 複雜度與取捨

時間 O(n)，額外空間 O(1)；排序再取最後一個通常 O(n log n)，還可能改變原陣列。若只需最大值，不必排序。

> [!WARN] 常見錯誤
> 只有一筆、重複值、全負數及空陣列都應測試；不要只手跑正數範例。
