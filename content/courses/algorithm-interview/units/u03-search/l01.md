## 為什麼要預處理

店家反覆查不同日期範圍的銷量。定義 `prefix[i]` 為前 i 筆之和，半開區間 `[left,right)` 的和便是 `prefix[right]-prefix[left]`。

```js
function prefixSums(values) {
  const prefix = [0];
  for (const value of values) prefix.push(prefix[prefix.length - 1] + value);
  return prefix;
}
function rangeSum(prefix, left, right) {
  return prefix[right] - prefix[left];
}
```

## 手跑與不變量

`[2,5,1,4]` 得 `[0,2,7,8,12]`。查 `[1,3)` 得 8-2=6，對應 5+1。每次新增一項後，**不變量**是 prefix 最後一項等於所有已讀值的總和。空區間 `[2,2)` 的差為 0。

## 複雜度與取捨

預處理 O(n) 時間、O(n) 空間，之後每次查詢 O(1)；只有一次短區間查詢時直接掃描可省空間。呼叫前須確認 `0 <= left <= right <= values.length`，否則索引越界。

> [!WARN] 索引
> `prefix[0]=0`，右界不包含在區間內；不要把 `[1,3)` 當作三筆資料。
