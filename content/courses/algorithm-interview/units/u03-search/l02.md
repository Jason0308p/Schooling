## 為什麼找左邊界

排序座位編號可能重複。要找**第一個不小於目標**的位置，而非任意相等位置；沒有符合元素時回傳陣列長度，方便後續插入。

```js
function lowerBound(sorted, target) {
  let left = 0, right = sorted.length;
  while (left < right) {
    const mid = left + Math.floor((right - left) / 2);
    if (sorted[mid] < target) left = mid + 1;
    else right = mid;
  }
  return left;
}
```

## 手跑與不變量

`[1,3,3,8]` 找 3：`[0,4)` 中點 2 值 3，右界變 2；`[0,2)` 中點 1 值 3，右界變 1；`[0,1)` 中點 0 值 1，左界變 1；回傳 1。**不變量**：左界之前都小於目標，右界及之後都不可能是更早的符合位置。每步縮短候選區間。

## 複雜度與取捨

已排序時 O(log n) 時間、O(1) 空間；若只查一次、資料未排序，先排序 O(n log n) 未必優於直接 O(n) 掃描。空陣列與所有值小於目標時都回傳 n。

> [!WARN] 邊界
> `right` 初始化為 n 而非 n-1，因為 n 本身也是合法的插入位置。
