## 遞迴與深度優先

團隊協作關係可看成圖；要找從某人可聯繫到哪些人。遞迴函式需要停止條件，圖可能有環，因此每個節點展開前先檢查是否已看過。

```js
function reachable(graph, start) {
  const seen = new Set();
  function dfs(node) {
    if (seen.has(node)) return;
    seen.add(node);
    for (const next of graph[node] ?? []) dfs(next);
  }
  dfs(start);
  return seen;
}
```

## 手跑與不變量

若 A→B、A→C、B→A：從 A 入集合，走 B；B 指回 A 已看過，返回；再走 C。結果 `{A,B,C}`。**不變量**：集合中的節點都能從起點抵達，且每個節點的鄰居最多展開一次。圖沒有 start 鍵時，本例仍將 start 視為可達自己。

## 複雜度與取捨

鄰接表下時間 O(V+E)、集合和遞迴堆疊最多 O(V) 額外空間；非常深的圖可能使呼叫堆疊溢位，可改用顯式堆疊。DFS 適合可達性，但首次找到的路徑不保證最少邊數。

> [!WARN] 常見錯誤
> 不標記已訪問節點會在 A→B→A 之間反覆呼叫。
