## 為什麼按層搜尋

倉庫間轉運關係為無權圖，主管要知道能否抵達目的地，面試官進一步問最少轉運次數。BFS 按距離逐層擴展，首次到達目標即為最少邊數。

```js
function minTransfers(graph, start, goal) {
  const queue = [[start, 0]];
  const seen = new Set([start]);
  for (let head = 0; head < queue.length; head++) {
    const [node, steps] = queue[head];
    if (node === goal) return steps;
    for (const next of graph[node] ?? []) {
      if (!seen.has(next)) {
        seen.add(next);
        queue.push([next, steps + 1]);
      }
    }
  }
  return null;
}
```

## 手跑與不變量

A→B、B→C：佇列先 `[[A,0]]`；展開 A 加入 `[B,1]`；展開 B 加入 `[C,2]`；取出 C 回傳 2。**不變量**：佇列按步數非遞減排列、每節點最多入列一次。若起點等於終點，回傳 0；不可達則回傳 null。

## 複雜度與面試表達

鄰接表下 O(V+E) 時間、O(V) 空間。使用 `head` 索引，避免反覆 `shift()` 可能產生搬移成本。面試先問方向、有無權重及不存在的站點如何處理；說明基線 DFS 可判可達但不保證最短，再講 BFS、測空圖與有環圖。若邊有不同權重，BFS 最少邊數不等於最低成本。

> [!TIP] 口述順序
> 規格 → 基線解 → 不變量 → 手跑邊界 → 複雜度與取捨。
