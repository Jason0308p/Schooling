## 連續兩天最忙的是哪一段？

客服有每日請求數 `[3,1,4,2]`，要找連續 `k=2` 天的最大總量。`n` 是天數，`k` 是區間長度；**連續**是必要條件，不能任挑兩天。

直覺方法：每個起點都重新加總接下來 `k` 天。這可得到 `3+1=4`、`1+4=5`、`4+2=6`，答案 6；但最壞要對約 `n-k+1` 個區間各做 `k` 次加法，時間 `O(nk)`（例如 `k` 約為 `n/2` 時，工作量接近平方）。相鄰兩段只有離開的一天與新進的一天不同，其他數字何必重算？

## 把上一段的和帶到下一段

從 `[3,1]` 的和 4 移到 `[1,4]`：**扣 3、加 4** 得 5；再移到 `[4,2]`：扣 1、加 2 得 6。這次沒有重新掃描整段。

```js
function maxWindow(values, k) {
  if (!Number.isInteger(k) || k < 1 || k > values.length) return null;
  let sum = 0;
  for (let i = 0; i < k; i++) sum += values[i];
  let best = sum;
  for (let i = k; i < values.length; i++) {
    sum += values[i] - values[i - k];
    best = Math.max(best, sum);
  }
  return best;
}
```

**不變量**：初始化後 `sum` 等於前 `k` 天的總量；每次移動，只有 `values[i-k]` 離開、`values[i]` 加入，所以更新後 `sum` 仍等於**當前**長度 `k` 的區間總和。`best` 則是到目前為止看過的最大總量。這同時說明為什麼不能漏掉第一段。

## 成本與邊界

先算第一段 `k` 次，其後最多更新 `n-k` 次，總計 `O(n)` 時間、`O(1)` 額外空間；沒有建立每段的副本。`k=0`、`k>n`、非整數或空資料回傳 `null`；`k=n` 只比較唯一的一段。若資料允許負數，也不能把 `best` 預設成 0：對 `[-5,-2,-3]`、`k=2` 應回傳 `-5`，不是 0。固定長視窗的加減法**不需要**資料非負。

> [!WARN] 別把固定長與可變長混成同一條規則
> 若改問「和至少達到門檻的最短連續區間」，常見的可變長視窗縮邊策略依賴非負數等單調條件。例如 `[-4,5]`、門檻 `5`：只看整段的和 1 便以為還沒達標、繼續擴張，可能漏掉單筆 `[5]`。那是另一題，不能直接套這裡的固定長更新法。
