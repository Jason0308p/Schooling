## 為什麼滑動視窗

客服要找連續 k 天的最大請求總量。不用每段重新相加：視窗右移一次，只要加入新的一天、扣掉離開的一天。

```js
function maxWindow(values, k) {
  if (k < 1 || k > values.length) return null;
  let sum = 0;
  for (let i = 0; i < k; i++) sum += values[i];
  let best = sum;
  for (let i = k; i < values.length; i++) {
    sum += values[i] - values[i - k];
    best = Math.max(best, sum);
  }
  return best;
}
```

## 手跑與不變量

`[3,1,4,2]`、k=2：初始和 4；右移加 4 減 3 得 5；再加 2 減 1 得 6。**不變量**：每輪更新後 sum 等於當前長度 k 的連續區間和。k=0 或 k 大於資料長度，本例回傳 null。

## 複雜度與取捨

時間 O(n)、額外空間 O(1)，逐段重算為 O(nk)。若改成依總和門檻縮放**可變長**視窗，通常需要元素非負，否則移動邊界不保證和單調改變；固定長度版本則可處理負數。

> [!TIP] 測試
> 另外測 k=1、k=n、全負數，避免 best 預設為 0。
