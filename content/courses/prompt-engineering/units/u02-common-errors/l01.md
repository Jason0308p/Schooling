## 常見錯誤與修正策略

就算你已經學了四個維度，有時候 AI 的輸出還是不對勁。

這一課我們來看三種最常見的失敗模式，以及具體的修正策略。

---

## 失敗模式一：Prompt 模糊，AI 靠猜

這是最常見的問題。當 Prompt 缺少關鍵資訊，AI 會用「最常見的情況」來填補空白。

### 診斷方法

如果 AI 的回答讓你想說「嗯⋯⋯對但不對」，通常就是 Prompt 太模糊了。

**測試方法：** 把你的 Prompt 給一個剛入職的實習生看，問他：「你知道要交出什麼嗎？」如果他也不確定，那 Prompt 就需要修正。

### 常見模糊點和修正

| 模糊點 | 模糊版本 | 修正版本 |
|--------|----------|----------|
| 沒有目標受眾 | 「幫我解釋 A/B 測試」 | 「用 3 句話向非技術背景的行銷主管解釋 A/B 測試」 |
| 沒有輸出格式 | 「分析一下這份數據」 | 「用條列式整理 3 個關鍵發現，每點 1 句話」 |
| 沒有使用情境 | 「幫我寫開會摘要」 | 「這是和客戶的需求確認會議，幫我整理：決議事項（條列）、待辦（誰負責、什麼時候）」 |

## 失敗模式二：任務太複雜，AI 力不從心

當一個任務包含多個步驟、多種判斷，一次全部丟給 AI，通常會得到表面的答案。

### 拆解策略

**原始 Prompt（太複雜）：**
```
幫我研究競爭對手、找出我們的差異化機會、寫一份策略報告、並設計一個 6 個月的行動計畫。
```

**拆解後（多輪對話）：**

**第一輪：** 縮小範圍
```
我要做 SaaS 專案管理工具的市場分析。
請先幫我列出 5 個主要競品，每個附上一句話定位和目標客群。
```

**第二輪：** 深入分析
```
好，就用這 5 個競品。
請用表格比較他們的定價模式（Free / Pro / Enterprise）和 3 個核心功能差異。
```

**第三輪：** 策略建議
```
根據這份比較，我們的產品在「小團隊易用性」有優勢，但缺乏企業整合功能。
請提出 3 個差異化策略方向，每個說明目標客群和執行優先級。
```

> [!TIP] 實務技巧
> 把複雜任務想成烹飪食譜：先備料（收集資料）→ 再料理（分析）→ 最後擺盤（輸出格式）。每步都要確認才進下一步。

## 失敗模式三：輸出不對勁，但不知道怎麼修

「感覺不好但說不清楚哪裡不好」是修正 Prompt 最常見的困境。

### 反向約束法

比起說「要更好」，更有效的是說「不要做 X」：

```
# 沒效的修正
這段文案感覺太商業，改得更有溫度一點。

# 有效的修正
請根據以下規則修改這段文案：
- 禁止使用的詞：「業界領先」「一站式」「賦能」「賦予」「顯著提升」
- 每個句子不超過 20 字
- 語氣改為朋友推薦，不是廣告
- 加入一個具體的使用場景（例如：「下班後想放鬆⋯⋯」）
```

### 提供反例

你也可以給 AI 看「你不想要什麼」：

```
我要你重寫這段，但要避免以下風格：

不好的範例：
「我們的革命性產品將徹底改變您的工作方式，為您帶來前所未有的效率提升。」

這樣太浮誇了。我要的是平實、具體、有一個實際用戶受益的例子。
```

> [!WARN] 常見錯誤
> 不要反覆說「再好一點」「調整一下」——這讓 AI 在原地打轉。每次修正都要給**具體的方向或禁止條件**。

---

## 修正 Prompt 的 SOP

當 AI 的輸出不符合預期，用這個流程診斷：

**Step 1：找缺失的維度**
問自己：Role、Task、Format、Context 哪一個缺了或不夠具體？

**Step 2：加約束而不是說「更好」**
把「感覺不對的地方」翻譯成「禁止做 X」或「必須包含 Y」。

**Step 3：拆解複雜需求**
如果任務有多個步驟，分輪完成，每輪只要求一件事。

**Step 4：給反例**
告訴 AI「這種風格是我不要的」比告訴它「我要什麼風格」更精準。

```
# 完整的修正 Prompt 結構
[說明問題]：你上一版的輸出問題是：___
[加約束]：請修改，遵守以下規則：
  1. 不要 ___
  2. 必須包含 ___
  3. 格式改為 ___
[加反例（可選）]：以下是我不想要的風格：___
```
