## 進階技巧：CoT、Few-shot、自我檢核

學完四個維度後，大多數的 Prompt 都能輸出不錯的結果。

這一課介紹三個進階技巧，讓你在複雜場景下進一步提升輸出的品質和穩定性。

---

## 技巧一：Chain of Thought（思維鏈）

### 什麼是 Chain of Thought？

Chain of Thought（CoT）是讓 AI **展示推理過程**的技巧。

預設情況下，AI 直接給你結論。CoT 要求 AI 把「它是怎麼想到這個結論的」也寫出來。

**沒有 CoT：**
```
這個功能值得做嗎？
```
→ AI 給你一個結論：「值得做，因為 blah blah」

**加上 CoT：**
```
這個功能值得做嗎？

請用以下步驟思考：
1. 分析這個功能解決了什麼用戶問題，以及問題的嚴重程度
2. 評估開發成本（高/中/低）和時間
3. 考慮和現有功能的衝突或協同效應
4. 列出支持和反對的理由
5. 根據以上，給出你的建議和信心程度

把每個步驟的思考過程都寫出來。
```

### 為什麼 CoT 讓輸出更好？

CoT 有兩個好處：
1. **提升品質**：AI 的中間推理步驟讓它不容易跳過關鍵判斷
2. **可驗證性**：你可以看到 AI 的推理邏輯，發現哪裡不對再糾正

### CoT 的適用場景

| 適合 CoT | 不需要 CoT |
|----------|------------|
| 商業決策分析 | 翻譯、格式轉換 |
| 風險評估 | 寫詩、創意生成 |
| 優先級排序 | 資料整理 |
| 診斷問題原因 | 簡單摘要 |

> [!TIP] 實務技巧
> 最簡單的 CoT 觸發語：在 Prompt 結尾加上「請一步一步思考」或「先列出你的推理過程，再給出結論」。

## 技巧二：Few-shot（給範例）

### 什麼是 Few-shot？

Few-shot 是在 Prompt 中**提供 2-3 個例子**，讓 AI 學習你想要的格式或風格。

這比用文字描述「我想要什麼風格」有效得多——因為例子比描述更精準。

### Few-shot 的典型應用

**場景：讓 AI 寫符合品牌語氣的社群貼文**

```
以下是我們品牌的社群貼文風格：

【範例 1】
「有時候最好的 Prompt 就是：把問題直接丟給 AI，
然後說「你覺得我問錯了嗎？」
試試看 🧪」

【範例 2】
「新功能上線：自動分類標籤。
測試了 200 份文件，準確率 94%。
還有 6% 讓我很好奇它在想什麼 🤔」

現在用相同的語氣（簡短、有點自嘲、帶實際數字或細節）寫一則關於 [主題] 的貼文。
```

### Few-shot 的注意事項

**給 2-3 個例子最有效**，太少學不到模式，太多（超過 5 個）反而讓 AI 困惑。

**例子要有代表性**——選你最喜歡的那種風格，不要選「普通」的。

```
# 應用於分類任務的 Few-shot

請根據以下例子，把剩下的用戶反饋分類：

範例：
- 「登入一直出錯，很煩」→ 類別：Bug 回報
- 「可以加個深色模式嗎？」→ 類別：功能請求
- 「客服態度很好，謝謝」→ 類別：正向反饋
- 「定價好貴，跟競品比不划算」→ 類別：定價意見

現在請分類以下反饋：
[貼入用戶反饋]
```

> [!WARN] 常見錯誤
> Few-shot 的例子本身要夠好——如果你的「範例」品質普通，AI 模仿出來的也會很普通。選你真正滿意的例子作為 Few-shot。

## 技巧三：自我檢核（Self-Review）

### 讓 AI 批判自己的輸出

AI 在產出模式下不容易發現自己的問題。但如果你讓它**切換成審查模式**，效果完全不同。

**無效的自我檢核：**
```
這份文件有問題嗎？
```
→ AI 通常說「看起來沒什麼問題」

**有效的自我檢核：**
```
請扮演一位嚴格的編輯，用以下標準審查剛才的文案：

□ 有沒有「業界領先」「顛覆性」「賦能」等空洞詞彙？
□ 每個主張都有具體依據嗎？（數字、例子、引用）
□ 有沒有超過 25 字的長句需要拆開？
□ 讀完 10 秒內，受眾知道這個產品幫他解決什麼問題嗎？

先列出所有問題，再問我要不要修正版本。
```

### 自我檢核的進階用法：角色切換

讓不同角色審查同一份輸出：

```
剛才你幫我寫了這份行銷提案。
現在請分別用以下角色的視角給回饋：

1. 懷疑論者：哪些主張缺乏依據？哪裡言過其實？
2. 目標客戶：作為一個忙碌的中小企業老闆，看完這份提案有什麼疑問？
3. 競品行銷團隊：我們的競爭對手看到這份提案會怎麼反駁？
```

> [!BIZ] 為什麼這個模板在工作中很有用
> 在把任何文件寄出或發布之前，用自我檢核讓 AI 做一輪「挑剔的讀者」審查，能抓住你在寫作時盲點看不到的問題。這比自己反覆看強得多，因為 AI 不會有「作者盲點」。

---

## 三個技巧的適用場景對照

| 技巧 | 最適合用在 | 不需要用在 |
|------|-----------|------------|
| **Chain of Thought** | 複雜決策、風險分析、多步驟推理 | 直接輸出型任務（翻譯、格式轉換） |
| **Few-shot** | 風格/語氣複製、分類任務、模板填充 | 通用知識型問題 |
| **自我檢核** | 任何要對外發布的重要文件 | 草稿階段、快速迭代中 |

## 課程總結

你現在掌握了讓 AI 輸出更穩定的完整工具箱：

1. **四個維度**（Role / Task / Format / Context）——Prompt 的基礎骨架
2. **修正策略**（反向約束 / 多輪拆解）——當輸出不對時的補救工具
3. **模板庫**（行銷 + PM）——常見工作場景的即用模板
4. **進階技巧**（CoT / Few-shot / 自我檢核）——提升複雜任務的品質上限

> [!TIP] 實務技巧
> 最快的進步方式：把你每天最常做的一個 AI 任務（寫文案、整理報告、起草 Email），用這套框架重新設計一個模板，存在你的筆記工具裡。第一次花 15 分鐘，之後每次省 10 分鐘。
