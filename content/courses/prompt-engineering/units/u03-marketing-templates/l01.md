## 行銷人的 Prompt 模板庫

這一課是純實用模板。每個模板都可以直接複製，替換 `[ ]` 裡的內容即可使用。

---

## 模板一：廣告文案（多平台）

### Facebook / Instagram 廣告

```
你是 D2C 品牌廣告文案師，擅長台灣消費者市場。

幫我為 [產品名稱] 寫 3 組廣告文案，每組包含：
- 主標題（15 字以內，製造好奇或痛點共鳴）
- 描述文字（40-60 字，說明產品如何解決問題）
- CTA 按鈕文字（5 字以內，如：立即搶購、免費試用）

產品資訊：
- 品類：[手工護膚品 / SaaS 工具 / 線上課程]
- 核心賣點：[填入 2-3 個賣點]
- 受眾：[年齡、性別、興趣]
- 目前痛點：[填入目標受眾的主要痛點]

禁止用詞：「業界領先」「獨家」「限時」（除非真的限時）「革命性」
語氣：[活潑 / 專業 / 溫暖]
```

### LinkedIn B2B 廣告

```
你是 B2B SaaS 廣告文案師，熟悉 LinkedIn 受眾心理。

幫我為 [產品名稱] 寫 3 組 LinkedIn 廣告文案：
- 標題：25 字以內
- 描述：75 字以內
- 開場方式：用數據或問題，不要從「我們是...」開始

產品：[產品描述，一句話說清楚它解決什麼問題]
目標受眾職位：[PM / 行銷主管 / 創辦人]
核心訴求：[節省時間 / 提升轉換率 / 降低成本]
禁止術語：[賦能、顛覆、賦予、革命性]
```

> [!TIP] 實務技巧
> LinkedIn 廣告的開場最忌諱從公司自我介紹開始。用「你有沒有這個問題？」或「X% 的 [職位] 都面臨...」開場點擊率更高。

## 模板二：SEO 文章起草

```
你是繁體中文 SEO 內容策略師，熟悉台灣搜尋習慣。

請幫我起草一篇 SEO 文章草稿：

主題：[文章主題]
主關鍵字：[主要 SEO 關鍵字]（在標題、引言、至少 3 個 H2 附近自然出現）
副關鍵字：[2-3 個相關關鍵字]

文章規格：
- 字數：1500-2000 字（繁體中文）
- 受眾：[目標讀者描述，如「想開始跑步的上班族」]
- 語氣：[親切實用 / 專業權威 / 故事性]

文章結構（請依此架構輸出）：
1. SEO 標題（H1，含主關鍵字，60 字以內）
2. 引言（說明讀者會在這篇文章得到什麼，100 字）
3. [H2 主題一]：[你想涵蓋的子主題]
4. [H2 主題二]
5. [H2 主題三]
6. 常見問題 FAQ（3 題，問答格式）
7. 結語 + CTA（推薦下一步行動）

注意：不要在文章中寫「首先」「其次」「最後」這類連接詞，直接進入內容。
```

> [!BIZ] 為什麼這個模板在工作中很有用
> 用 AI 起草 SEO 文章的最佳方式是：先用模板產出結構草稿，再自己加入真實案例、數據和品牌觀點。AI 負責架構，你負責讓它有靈魂。

## 模板三：競品分析

```
你是商業策略分析師，熟悉 [產業名稱] 市場。

請分析以下競品：[競品 A、B、C、D]

輸出格式：Markdown 表格，欄位：
| 品牌 | 定價（月費） | 核心功能（3 項） | 目標客群 | 主要弱點 | 對我們的威脅（高/中/低） |

分析完表格後，輸出：
**策略摘要（3 句話以內）：**
- 我們最應該關注哪個競品？為什麼？
- 市場上目前缺少什麼機會？
- 我們有哪個差異化優勢可以放大？

背景：我們的產品是 [一句話描述]，目前主要用戶是 [用戶描述]。
```

## 模板四：數據報告整理

```
你是數據分析師，擅長把複雜數據翻譯成行動建議。

請幫我整理以下行銷數據的洞察報告：
[貼入你的原始數據或表格]

輸出格式：
## 本期表現摘要（5 點以內條列，每點 1 句話）
## 3 個關鍵發現（每個發現 2-3 句，說明數字背後的意義）
## 2 個需要立刻行動的問題
## 下期建議優先事項（條列，附預期效果）

受眾：行銷主管，看報告時間不超過 3 分鐘。
語氣：直接、結論先行，不要使用「值得注意的是」這類廢話。
數據時間範圍：[填入時間段]
對比基準：[和上個月 / 和去年同期 / 和目標值比較]
```

> [!WARN] 常見錯誤
> 不要把所有數據一次丟給 AI，然後問「你覺得怎麼樣？」。先告訴 AI 你最關心的指標是什麼，以及你想要什麼格式的輸出——這樣才能得到真正有用的洞察，而不是對數據的表面描述。
