## Excel 的做法 vs SQL 的做法

你在 Excel 裡做報表大概是這樣：選幾欄複製、開篩選器點一點、點欄位標頭排序。
SQL 把這三個動作變成三個關鍵字：**SELECT、WHERE、ORDER BY**。

## 選欄位 → SELECT

Excel：用滑鼠點選你要的欄，按 Ctrl+C。

SQL：把欄位名稱寫在 `SELECT` 後面，用逗號隔開。

```sql run
SELECT product_name, category, price
FROM products;
```

`FROM` 告訴 SQL 要去哪張表拿資料。順序就是這樣：先說要**哪些欄位**（SELECT），再說來自**哪張表**（FROM）。

> [!TIP] 給 Excel 用戶的小提示
> 第一次用 SQL 最容易犯的錯：把 `FROM` 寫在 `SELECT` 前面。記住 SQL 的語意是「**給我（SELECT）這幾欄，從（FROM）這張表**」，照這個順序寫就不會錯。

想要全部欄位？用 `*`（星號）：

```sql run
SELECT *
FROM products
LIMIT 5;
```

> [!BIZ] 為什麼 SQL 比 Excel 更適合這個情境
> Excel 選欄位是手動操作，下次要再做一次就要重做。SQL 是**文字**，寫好存起來，下次直接貼上，永遠一樣、不會選錯欄。

## 篩選資料 → WHERE

Excel：點上方的篩選器，勾你要的值。

SQL：在查詢裡加一行 `WHERE 條件`。

```sql run
SELECT order_id, order_date, total_amount
FROM orders
WHERE status = 'completed';
```

文字值要用**單引號**包起來：`'completed'`。數字不用：

```sql run
SELECT product_name, price
FROM products
WHERE price >= 500;
```

> [!TIP] 給 Excel 用戶的小提示
> Excel 篩選器是「勾選你要留下的值」；SQL WHERE 是「描述你要留下的條件」。兩個概念完全一樣，只是一個點滑鼠，一個打文字。

多個條件用 `AND` 或 `OR` 串起來（就像 Excel 篩選器的「且」和「或」）：

```sql run
SELECT order_id, order_date, total_amount
FROM orders
WHERE status = 'completed'
  AND total_amount >= 1000;
```

> [!DIALECT] 不同資料庫都一樣
> `SELECT … FROM … WHERE …` 是標準 SQL，在 SQLite、PostgreSQL、MySQL、BigQuery 語法完全相同，可以直接複製貼上。

## 排序 → ORDER BY

Excel：點欄位標頭旁的小三角形。

SQL：在查詢最後加 `ORDER BY 欄位名稱`。

```sql run
SELECT product_name, price
FROM products
ORDER BY price DESC
LIMIT 10;
```

- `DESC`（descending）= 由大到小、由新到舊
- `ASC`（ascending，預設）= 由小到大、由舊到新

> [!BIZ] 為什麼 SQL 比 Excel 更適合這個情境
> Excel 每次開舊檔案都要重新排序。SQL 的排序寫在查詢裡，每次執行結果永遠一致，不怕同事手滑點了別的欄位。

## 把三個動作合在一起

現在你已經有三個積木了。把它們組起來：

```sql run
SELECT order_id, order_date, total_amount
FROM orders
WHERE status = 'completed'
ORDER BY total_amount DESC
LIMIT 5;
```

執行順序是：先去表（FROM）→ 篩選（WHERE）→ 選欄位（SELECT）→ 排序（ORDER BY）→ 取前幾筆（LIMIT）。

> [!TIP] 給 Excel 用戶的小提示
> SQL 的**書寫順序**（SELECT → FROM → WHERE → ORDER BY）和**執行順序**不同。執行順序是 FROM → WHERE → SELECT → ORDER BY。這在後面學 GROUP BY 和 HAVING 時很重要，現在先記住：寫的時候按照上面的格式寫，不會錯。
