## 函數翻譯對照表

你在 Excel 裡每天用的函數，在 SQL 都有對應版本：

| Excel 函數 | SQL 對應 | 用途 |
|---|---|---|
| `IF(條件, 值1, 值2)` | `CASE WHEN 條件 THEN 值1 ELSE 值2 END` | 條件判斷 |
| `IFS(條件1, 值1, 條件2, 值2, ...)` | `CASE WHEN 條件1 THEN 值1 WHEN 條件2 THEN 值2 END` | 多條件 |
| `IFERROR(值, 備用值)` | `COALESCE(值, 備用值)` | NULL 處理 |
| `IFNA(值, 備用值)` | `COALESCE(值, 備用值)` | NULL 處理 |
| `CONCATENATE(A, B)` 或 `A & B` | `A \|\| B` | 串接文字 |
| `TEXT(日期, "YYYY-MM")` | `strftime('%Y-%m', 日期)` | 日期格式化 |

## IF → CASE WHEN

Excel：
```
=IF(D2="completed","已完成","其他")
```

SQL：
```sql run
SELECT
  order_id,
  CASE WHEN status = 'completed' THEN '已完成' ELSE '其他' END AS status_label
FROM orders
LIMIT 10;
```

多個條件（對應 Excel 的 IFS）：

```sql run
SELECT
  order_id,
  CASE status
    WHEN 'completed' THEN '已完成'
    WHEN 'cancelled' THEN '已取消'
    WHEN 'refunded' THEN '已退款'
    ELSE '處理中'
  END AS status_label
FROM orders
LIMIT 10;
```

> [!TIP] 給 Excel 用戶的小提示
> `CASE 欄位 WHEN 值 THEN 結果` 是針對單一欄位比對固定值的簡寫。如果條件是範圍或運算式（例如 `price > 500`），就要寫完整版：`CASE WHEN price > 500 THEN '高價' ELSE '一般' END`。

## IFERROR / IFNA → COALESCE

Excel 遇到 VLOOKUP 找不到的值時會回傳 `#N/A`，你用 `IFERROR` 把它換成備用值：
```
=IFERROR(VLOOKUP(A2,...), "未知")
```

SQL 用 `COALESCE`：第一個不是 NULL 的值就回傳。

```sql run
SELECT
  customer_id,
  name,
  COALESCE(city, '（未填寫）') AS city_display
FROM customers
LIMIT 10;
```

`COALESCE` 可以接多個參數，依序找第一個非 NULL 的值：
```sql run
SELECT
  customer_id,
  COALESCE(city, '（未填寫）') AS city_display
FROM customers
WHERE city IS NULL
LIMIT 5;
```

> [!BIZ] 為什麼 SQL 比 Excel 更適合這個情境
> Excel 的 `IFERROR` 會把所有錯誤都吃掉（包括公式寫錯）。SQL 的 `COALESCE` 只處理 NULL，不會遮蓋真正的查詢錯誤，比較安全。

## CONCATENATE / & → ||

Excel：`=A2&" ("&B2&")"`

SQL：`name || ' (' || city || ')'`

```sql run
SELECT
  customer_id,
  name || ' <' || email || '>' AS contact_label
FROM customers
LIMIT 10;
```

## TEXT(日期) → strftime

Excel：`=TEXT(A2, "YYYY-MM")` 把日期格式化成年月

SQL（SQLite）：`strftime('%Y-%m', order_date)`

```sql run
SELECT
  strftime('%Y-%m', order_date) AS month,
  COUNT(*) AS order_count
FROM orders
GROUP BY month
ORDER BY month;
```

> [!DIALECT] 日期格式化語法
> | 資料庫 | 函數 | 年月格式 |
> |---|---|---|
> | SQLite | `strftime('%Y-%m', 欄位)` | `'%Y-%m'` |
> | PostgreSQL | `TO_CHAR(欄位, 'YYYY-MM')` | `'YYYY-MM'` |
> | BigQuery | `FORMAT_DATE('%Y-%m', 欄位)` | `'%Y-%m'` |
> | MySQL | `DATE_FORMAT(欄位, '%Y-%m')` | `'%Y-%m'` |
