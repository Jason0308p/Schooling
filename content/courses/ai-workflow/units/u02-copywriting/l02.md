## 社群內容生成：IG、LinkedIn、Dcard、部落格

每個平台有自己的「語言」。同一個訊息，在 IG 用輕鬆 emoji，在 LinkedIn 要用數據和商業洞察，在 Dcard 要像朋友聊天，在部落格要有深度和 SEO 結構。AI 最大的價值是讓你一份素材變成五份內容。

---

## 平台語氣速查表

| 平台 | 語氣風格 | 長度 | 特殊需求 |
|------|---------|------|---------|
| **Instagram** | 輕鬆、視覺驅動、情感 | 50–150 字 | Hashtag 13–20 個 |
| **LinkedIn** | 專業、洞察、數據佐證 | 200–400 字 | 開頭要有鉤子，結尾問問題 |
| **Dcard** | 口語、好奇心、討論感 | 100–300 字 | 像朋友分享，帶問句引討論 |
| **部落格** | 結構化、深度、SEO | 800–1500 字 | H2/H3 標題、關鍵字密度 |
| **Facebook** | 社交、分享性強 | 100–200 字 | 適合帶連結或圖片 |

## Instagram 貼文

### Prompt 範本

```
你是一位台灣 IG 社群經營專家，擅長寫高互動貼文。

品牌/帳號定位：[說明帳號是什麼、受眾是誰]
這篇貼文的主題：[一句話說明]
想傳遞的核心訊息：[最重要的 1–2 個點]
圖片內容（如有）：[說明配圖主要畫面]

請生成：
1. 貼文內文（100–150 字，繁體中文）
   - 第一行是鉤子（讓人想繼續讀）
   - 用換行和 emoji 增加可讀性
   - 最後一行是互動問句或 CTA
2. Hashtag 組合（13 個）：
   - 大眾標 3 個（使用量 100萬+）
   - 中眾標 5 個（使用量 10–100萬）
   - 利基標 5 個（使用量 1–10萬，與主題高度相關）
```

## LinkedIn 貼文

### 結構公式

LinkedIn 演算法偏好**個人觀點 + 具體數據 + 故事**的組合。

```
開頭鉤子（1–2 行，讓人想點「更多」）

↓

核心內容（3–5 個要點，用數字或小標分段）

↓

具體案例或數據

↓

結論 + 邀請留言的問題
```

### Prompt 範本

```
你是一位在台灣的行銷/PM 專業人士，LinkedIn 有 2000+ 連結。

貼文主題：[你想分享的工作洞察、工具、案例或職涯觀點]
你的立場/觀點：[你的核心主張是什麼]
如有數據：[具體數字或案例]

請生成一篇 LinkedIn 貼文：
- 開頭第一行要讓人想點「更多」（不要用「今天想跟大家分享」這類廢話開頭）
- 總長度 200–300 字
- 用空行分段，不用 bullet point 符號（LinkedIn 不支援 markdown）
- 結尾問一個開放式問題邀請留言
- 語氣：專業但不失個人特色
```

> [!TIP] **LinkedIn 開頭技巧**
> 避免以下無聊開頭：「今天想分享…」「很榮幸…」「最近在思考…」
>
> 改用這些格式：「3 年前我犯了一個錯誤…」「大多數人不知道的是…」「一個數字讓我改變了做法：[數字]」

## Dcard 討論串

### 特性
- 匿名文化，口語化
- 讀者來看「真實心得」，不喜歡廣告感
- 帶問題或討論點才有互動

### Prompt 範本

```
你是一個 Dcard 重度使用者，想在女孩版/美妝版/職場板分享心得。

主題：[你想分享的產品/經驗/觀點]
你的真實使用情境：[為什麼用、怎麼用、什麼感受]
你想引發的討論：[想問大家什麼]

請用 Dcard 的口語風格寫一篇文：
- 開頭像朋友在說話，不要太正式
- 150–250 字
- 中間分享真實使用感受（包含一個小缺點，更有真實感）
- 結尾問一個問題讓大家回覆
- 不要用 emoji 過多，Dcard 風格偏文字
```

## 一篇內容變五篇

這是 AI 最強大的應用之一。你有一篇部落格文章，可以用這個 prompt 一次生成所有版本：

```
以下是一篇 [主題] 的部落格文章：

[貼上全文]

請幫我改寫成以下 4 個版本：

1. Instagram 貼文（100 字 + 15 個 hashtag）
2. LinkedIn 貼文（250 字，專業語氣，結尾有問題）
3. Dcard 分享文（200 字，口語風格，帶討論問題）
4. Twitter/X 串（5 則，每則不超過 280 字元英文 / 140 中文字）

每個版本請依序輸出，用「---」分隔。
```

> [!BIZ] **實際工作情境**
> 行銷團隊每週發布 1 篇深度部落格，用這個方法同時產出該週所有社群素材，社群更新頻率從每週 1 次提升到每日更新，但實際寫作時間沒有增加。
