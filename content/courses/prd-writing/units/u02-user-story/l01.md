## User Story：說需求的語言

功能清單（Feature List）是最常見的需求寫法，但它有一個根本問題：**它告訴工程師要做什麼，卻沒有告訴他們為什麼。**

「新增社群分享按鈕」——分享到哪裡？哪種使用者最需要？分享之後要做什麼追蹤？這些問題，功能清單回答不了。

User Story 的出現，就是為了把「使用者」放回需求的核心。

---

## User Story 的標準格式

```
As a [使用者角色],
I want [功能或能力],
so that [目的或使用者價值].
```

三個部分缺一不可：

- **As a**：誰在使用？要夠具體，不能只說「使用者」。
- **I want**：要做什麼？描述能力，不是實作細節。
- **So that**：為什麼要這個功能？使用者得到什麼價值？

**範例：**

> As a **returning customer（回購客戶）**,
> I want to **reorder my previous purchase with one click**,
> so that I don't have to search for the same items again.

---

## 三個常見的錯誤寫法

### 錯誤 1：使用者角色太模糊

❌ `As a user, I want to search products...`

問題：「user」太廣泛。不同使用者類型（訪客、會員、VIP）對搜尋的需求可能完全不同。

✅ `As a **first-time visitor（首次訪客）**, I want to search products without logging in...`

---

### 錯誤 2：I want 描述的是實作，不是能力

❌ `I want a dropdown menu with filter options`

問題：「dropdown menu」是 UI 設計決策，不是使用者需求。設計師可能有更好的方案。

✅ `I want to **filter products by price range and category**`

> [!TIP] 實務建議
> 檢查 I want 的方法：問自己「如果用不同的 UI 實作，這個 Story 還成立嗎？」如果答案是否，代表你寫的是解法，不是需求。

---

### 錯誤 3：So that 是廢話或缺失

❌ `so that I can use the filter feature`（循環定義）

❌ `so that it works properly`（沒有意義）

✅ `so that I can quickly narrow down 500+ products to find the one that fits my budget`

So that 應該說明：使用者的**生活或工作**因此變得更好的地方。

---

## User Story 的粒度

**太大的 Story（Epic）：**
> As a seller, I want a complete store management system.

這是一個 Epic，需要拆成多個 Story 才能在一個 Sprint 內完成。

**適當大小的 Story：**
> As a seller, I want to **upload product photos with a drag-and-drop interface**, so that I can quickly add product listings without technical knowledge.

判斷粒度的原則：一個 Story 應該可以在**一個 Sprint（1-2 週）** 內設計、開發、測試完成。

> [!WARN] 常見錯誤
> Story 拆得越小越好是個迷思。太小的 Story 缺乏足夠的業務背景，工程師在實作時反而難以做出正確的技術決策。找到「能獨立交付價值」的最小單位。

---

## User Story vs 功能清單

| 面向 | 功能清單 | User Story |
|---|---|---|
| 視角 | 系統功能 | 使用者目標 |
| 說明範圍 | 做什麼 | 誰做、為什麼做 |
| 工程師解讀空間 | 小（規格導向）| 大（目標導向）|
| 適合場景 | 詳細 Spec 文件 | PRD、Sprint Planning |

> [!BIZ] 業務背景
> Spotify 的 PM 團隊有一個內部原則：每個 Story 都要能通過「電梯測試」——在 30 秒內，對任何一個新加入的同事說清楚這個 Story 解決了誰的什麼問題。如果說不清楚，Story 還不夠好。
