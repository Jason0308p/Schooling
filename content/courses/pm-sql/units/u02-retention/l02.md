## Cohort 留存表

Cohort 是同一註冊月份的用戶群。比較各月留存可提出調查假設，但逐月改善不證明改版有效，來源組成與季節性也可能混淆。

- W1 = 註冊後 D1–7。
- W2 = D8–14。
- W4 = **註冊後第 4 週 D22–28**，不是滿四週之後。
- 資料起點/截止為 2025-01-01/2025-12-31（含），練習限 2025-01 至 2025-06 註冊 cohort。
- 單期 W1 納入完整走到 D7 的用戶；W1/W2/W4 同表採完整走到 D28 的共同母體。所有用戶須自註冊起可觀測，未成熟者不進分母。

先每人每期 MAX(flag)，再按 cohort 月彙總；沒回訪的合格者仍進分母。橫向比較不同週，縱向比較不同 cohort 同一週。每個週窗獨立判定，後期回訪不要求早期也回訪，所以比例不保證逐週遞減。

> [!WARN] 形狀不是原因
> 衰減或回升是調查線索，不是新手引導、核心價值或改版效果的因果證據。排名按指定精度比例，同分依 cohort_month ASC。

> [!DIALECT] SQLite
> strftime 取 cohort 月、julianday 算日期差；換資料庫需換對應日期函數。

### 按 Cohort 月計算 Week 1 留存率

```sql run
WITH cohort_retention AS (
  SELECT
    strftime('%Y-%m', u.signup_date) AS cohort_month,
    u.user_id,
    MAX(CASE WHEN julianday(da.log_date) - julianday(u.signup_date) BETWEEN 1 AND 7
             THEN 1 ELSE 0 END) AS w1
  FROM users u
  LEFT JOIN daily_active da ON da.user_id = u.user_id
  WHERE u.signup_date BETWEEN '2025-01-01' AND '2025-06-30' AND u.signup_date >= '2025-01-01' AND date(u.signup_date, '+7 days') <= '2025-12-31'
  GROUP BY u.user_id, cohort_month
)
SELECT
  cohort_month,
  COUNT(*)                              AS cohort_size,
  SUM(w1)                               AS w1_retained,
  ROUND(SUM(w1) * 100.0 / COUNT(*), 2) AS w1_pct
FROM cohort_retention
GROUP BY cohort_month
ORDER BY cohort_month;
```

### 完整 Cohort 留存表（W1 / W2 / W4）

```sql run
WITH flags AS (
  SELECT
    strftime('%Y-%m', u.signup_date) AS cohort_month,
    u.user_id,
    MAX(CASE WHEN julianday(da.log_date)-julianday(u.signup_date) BETWEEN 1  AND 7  THEN 1 ELSE 0 END) AS w1,
    MAX(CASE WHEN julianday(da.log_date)-julianday(u.signup_date) BETWEEN 8  AND 14 THEN 1 ELSE 0 END) AS w2,
    MAX(CASE WHEN julianday(da.log_date)-julianday(u.signup_date) BETWEEN 22 AND 28 THEN 1 ELSE 0 END) AS w4
  FROM users u
  LEFT JOIN daily_active da ON da.user_id = u.user_id
  WHERE u.signup_date BETWEEN '2025-01-01' AND '2025-06-30' AND u.signup_date >= '2025-01-01' AND date(u.signup_date, '+28 days') <= '2025-12-31'
  GROUP BY u.user_id, cohort_month
)
SELECT
  cohort_month,
  COUNT(*)                              AS cohort_size,
  ROUND(SUM(w1) * 100.0 / COUNT(*), 1) AS w1_pct,
  ROUND(SUM(w2) * 100.0 / COUNT(*), 1) AS w2_pct,
  ROUND(SUM(w4) * 100.0 / COUNT(*), 1) AS w4_pct
FROM flags
GROUP BY cohort_month
ORDER BY cohort_month;
```

### 找出留存率最差的 Cohort

```sql run
WITH flags AS (
  SELECT
    strftime('%Y-%m', u.signup_date) AS cohort_month,
    u.user_id,
    MAX(CASE WHEN julianday(da.log_date)-julianday(u.signup_date) BETWEEN 1 AND 7
             THEN 1 ELSE 0 END) AS w1
  FROM users u
  LEFT JOIN daily_active da ON da.user_id = u.user_id
  WHERE u.signup_date BETWEEN '2025-01-01' AND '2025-06-30' AND u.signup_date >= '2025-01-01' AND date(u.signup_date, '+7 days') <= '2025-12-31'
  GROUP BY u.user_id, cohort_month
)
SELECT
  cohort_month,
  COUNT(*)                              AS cohort_size,
  SUM(w1)                               AS w1_retained,
  ROUND(SUM(w1) * 100.0 / COUNT(*), 2) AS w1_pct
FROM flags
GROUP BY cohort_month
ORDER BY w1_pct ASC, cohort_month ASC
LIMIT 2;
```
