## Day 1 / Day 7 / Day 30 留存率

要評估新手留存，必須先看得到完整觀察窗。資料起點/截止固定為 **2025-01-01/2025-12-31（含）**，不是查詢當天，也不是最後一筆事件日期。

| 指標 | 註冊後觀察日數 | 單期成熟條件 |
|---|---|---|
| D1 | D1–2 | signup_date + 2 天 ≤ 截止 |
| D7 | D6–8 | signup_date + 8 天 ≤ 截止 |
| D30 | D28–32 | signup_date + 32 天 ≤ 截止 |

另外排除資料起點前註冊者，避免把不可觀測當未留存。多期同表題的 D1/D7/D30 **統一採可完整觀察 D32 的共同母體與分母**，不是各期使用不同用戶。這是本課自訂的區間留存，不是精確第 N 天留存。

先 LEFT JOIN 保留沒有回訪的合格者，MAX(CASE WHEN) 每人每期打一次 flag，再彙總；不可把回訪條件移到 WHERE 導致零留存者被刪掉。也不能把多次登入算作多人。

> [!WARN] 相關不等於因果
> Pro/Free 的差異可能源於來源、註冊月份、自選偏差及當前方案標籤，不能直接證明付費功能提升留存。沒有跨產品通用的「健康 App」留存門檻。

> [!DIALECT] 日期粒度
> 本課 YYYY-MM-DD 用 julianday 算日期差、date 加天數。不要把任意時間戳的小數日差直接套作日期規則。

### 計算整體 Day 7 留存率

```sql run
SELECT
  COUNT(DISTINCT u.user_id)                      AS total_users,
  COUNT(DISTINCT da.user_id)                     AS retained_users,
  ROUND(COUNT(DISTINCT da.user_id) * 100.0
        / COUNT(DISTINCT u.user_id), 2)          AS day7_retention_pct
FROM users u
LEFT JOIN daily_active da
  ON  da.user_id  = u.user_id
  AND julianday(da.log_date) - julianday(u.signup_date) BETWEEN 6 AND 8
WHERE u.signup_date >= '2025-01-01' AND date(u.signup_date, '+8 days') <= '2025-12-31';
```

### 同時計算 Day 1 / Day 7 / Day 30 留存率

```sql run
WITH retention AS (
  SELECT
    u.user_id,
    MAX(CASE WHEN julianday(da.log_date) - julianday(u.signup_date) BETWEEN 1 AND 2   THEN 1 ELSE 0 END) AS d1,
    MAX(CASE WHEN julianday(da.log_date) - julianday(u.signup_date) BETWEEN 6 AND 8   THEN 1 ELSE 0 END) AS d7,
    MAX(CASE WHEN julianday(da.log_date) - julianday(u.signup_date) BETWEEN 28 AND 32 THEN 1 ELSE 0 END) AS d30
  FROM users u
  LEFT JOIN daily_active da ON da.user_id = u.user_id
  WHERE u.signup_date >= '2025-01-01' AND date(u.signup_date, '+32 days') <= '2025-12-31'
  GROUP BY u.user_id
)
SELECT
  COUNT(*)                              AS total_users,
  ROUND(SUM(d1)  * 100.0 / COUNT(*), 2) AS d1_pct,
  ROUND(SUM(d7)  * 100.0 / COUNT(*), 2) AS d7_pct,
  ROUND(SUM(d30) * 100.0 / COUNT(*), 2) AS d30_pct
FROM retention;
```

### 比較 Pro vs Free 用戶的 Day 30 留存率

```sql run
WITH retention AS (
  SELECT
    u.user_id,
    u.plan,
    MAX(CASE WHEN julianday(da.log_date) - julianday(u.signup_date) BETWEEN 28 AND 32 THEN 1 ELSE 0 END) AS d30
  FROM users u
  LEFT JOIN daily_active da ON da.user_id = u.user_id
  WHERE u.plan IN ('pro', 'free') AND u.signup_date >= '2025-01-01' AND date(u.signup_date, '+32 days') <= '2025-12-31'
  GROUP BY u.user_id, u.plan
)
SELECT
  plan,
  COUNT(*)                               AS total_users,
  SUM(d30)                               AS retained_d30,
  ROUND(SUM(d30) * 100.0 / COUNT(*), 2) AS d30_pct
FROM retention
GROUP BY plan
ORDER BY d30_pct DESC, plan ASC;
```
