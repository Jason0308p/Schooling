## DAU 與 MAU：日活躍 vs 月活躍用戶

產品週報要區分每天使用人數與整月觸及人數。本課以 daily_active 有紀錄定義活躍，日期格式為 YYYY-MM-DD。

| 指標 | 定義 |
|---|---|
| DAU | 當日不重複活躍 user_id 數 |
| MAU | 指定日曆月不重複活躍 user_id 數 |
| YAU | 指定日曆年不重複活躍 user_id 數 |

月平均 DAU 要先建立完整 2025 年日曆，LEFT JOIN 活躍紀錄補出零日，再按月平均。COUNT DISTINCT 去掉同人多次活動；MAU 不是 DAU 加總，也不是 session 數。

> [!WARN] 資料完整是補零前提
> 本課假定觀測完整；真實資料須排除追蹤故障，不能把漏送事件直接當零。users.plan 是當前快照，不能當成每個月的歷史方案。

> [!DIALECT] SQLite 日期
> 遞迴 CTE 產生日曆、strftime 取年月；其他引擎改用對應日期函數或日期維度。

### 計算 2025 年每月 DAU 平均值

```sql run
WITH RECURSIVE calendar(log_date) AS (
  SELECT '2025-01-01'
  UNION ALL SELECT date(log_date, '+1 day') FROM calendar WHERE log_date < '2025-12-31'
), daily_dau AS (
  SELECT strftime('%Y-%m', c.log_date) AS month, c.log_date,
         COUNT(DISTINCT da.user_id) AS dau
  FROM calendar c LEFT JOIN daily_active da ON da.log_date = c.log_date
  GROUP BY c.log_date
)
SELECT
  month,
  ROUND(AVG(dau)) AS avg_dau
FROM daily_dau
GROUP BY month
ORDER BY month;
```

### 計算 2025 年每月 MAU

```sql run
SELECT
  strftime('%Y-%m', log_date) AS month,
  COUNT(DISTINCT user_id) AS mau
FROM daily_active
WHERE log_date >= '2025-01-01' AND log_date < '2026-01-01'
GROUP BY month
ORDER BY month;
```

### 各方案用戶的月活比較

```sql run
SELECT
  strftime('%Y-%m', da.log_date) AS month,
  u.plan,
  COUNT(DISTINCT da.user_id) AS mau
FROM daily_active da
JOIN users u ON u.user_id = da.user_id
WHERE da.log_date >= '2025-01-01' AND da.log_date < '2026-01-01'
GROUP BY month, u.plan
ORDER BY month, u.plan;
```
