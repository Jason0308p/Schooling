# DAU 與 MAU：日活躍 vs 月活躍用戶

## 什麼是 DAU 和 MAU？

| 指標 | 定義 | 用途 |
|------|------|------|
| **DAU**（Daily Active Users）| 某天至少開啟過一次 App 的不重複用戶數 | 追蹤短期健康度、觀察每日波動 |
| **MAU**（Monthly Active Users）| 某月至少登入過一次的不重複用戶數 | 評估產品覆蓋範圍、向投資人報告 |

## 資料表說明

本單元使用 `daily_active` 和 `users` 兩張表：

```sql
-- daily_active：每位活躍用戶每天一列
SELECT * FROM daily_active LIMIT 5;

-- users：用戶基本資料，含 plan、country、is_active
SELECT * FROM users LIMIT 5;
```

## 計算 DAU

```sql
-- 每天的 DAU
SELECT
  log_date,
  COUNT(DISTINCT user_id) AS dau
FROM daily_active
GROUP BY log_date
ORDER BY log_date;
```

## 計算 MAU

```sql
-- 每月的 MAU（用 strftime 取出年月）
SELECT
  strftime('%Y-%m', log_date) AS month,
  COUNT(DISTINCT user_id)     AS mau
FROM daily_active
GROUP BY month
ORDER BY month;
```

## 常見誤區

- **DAU ≠ 每天的 session 數**：一個用戶同天開 3 次只算 1 個 DAU
- **MAU 不是 DAU 的加總**：一個用戶當月每天都用，MAU 算 1 次，DAU 加總算 30 次
