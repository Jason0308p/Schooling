# Stickiness = DAU / MAU

## 什麼是 Stickiness？

**Stickiness（黏性）** 衡量「月活用戶中，平均每天有多少比例在使用產品」。

```
Stickiness = 平均 DAU ÷ MAU × 100%
```

| Stickiness | 解讀 |
|-----------|------|
| 50% | 月活用戶平均每 2 天用一次 |
| 25% | 月活用戶平均每 4 天用一次 |
| 10% | 月活用戶平均每 10 天用一次 |

## 業界參考值

- **社交/通訊 App**（Facebook、LINE）：40–60%
- **工具型 SaaS**：15–30%
- **低頻消費 App**：5–15%

## 計算範例

```sql
WITH daily_dau AS (
  SELECT
    log_date,
    strftime('%Y-%m', log_date) AS month,
    COUNT(DISTINCT user_id) AS dau
  FROM daily_active
  GROUP BY log_date
)
SELECT
  month,
  ROUND(AVG(dau), 0)                                AS avg_dau,
  (SELECT COUNT(DISTINCT user_id)
   FROM daily_active
   WHERE strftime('%Y-%m', log_date) = d.month)     AS mau
FROM daily_dau d
GROUP BY month
ORDER BY month;
```

## 為什麼用「平均 DAU」而不是「某一天 DAU」？

單天 DAU 受假日、節日影響大，用「月平均 DAU」更能反映整體趨勢。
