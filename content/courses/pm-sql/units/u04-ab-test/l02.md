# 統計顯著性判斷（Z-test）

## 為什麼需要統計顯著性？

如果 treatment CVR = 10.5%，control CVR = 10.0%，這個 0.5% 的差距是真實改善，還是隨機波動？

**統計顯著性**告訴我們：這個差距不太可能是偶然發生的（p < 0.05 = 95% 信賴水準）。

## 雙樣本比例 Z-test

```
p1 = control CVR（小數形式）
p2 = treatment CVR（小數形式）
n1 = control 樣本數
n2 = treatment 樣本數
p_pool = (控制組轉換數 + 實驗組轉換數) / (n1 + n2)
se = sqrt(p_pool × (1 - p_pool) × (1/n1 + 1/n2))
z = (p2 - p1) / se
```

## Z-score 判斷標準

| Z-score | 信賴水準 | 結論 |
|---------|---------|------|
| > 1.96  | 95%     | 顯著，可以做決策 |
| > 2.58  | 99%     | 非常顯著 |
| < 1.96  | < 95%   | 不顯著，需繼續觀察或擴大樣本 |

## SQLite 的 SQRT 替代

SQLite 沒有 `SQRT()`，改用 `POWER(x, 0.5)`：

```sql
-- 等價：SQRT(0.09) = POWER(0.09, 0.5) = 0.3
SELECT POWER(0.09, 0.5);
```

## 注意事項

1. **不要提前停止實驗**（Peeking Problem）：看到 z > 1.96 就馬上停止，會導致假陽性率升高
2. **樣本數需足夠**：樣本太小，z-test 不準確，建議提前計算最小樣本數
3. **多重測試問題**：同時跑多個實驗時，顯著性閾值要更嚴格
