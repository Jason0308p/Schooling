## 判斷統計顯著性（用 SQL 近似計算）

轉換率的差距可能包含抽樣波動。此課使用雙樣本比例 Z-test 的常態近似：

p_c = control 轉換數/n_c，p_t = treatment 轉換數/n_t。
p_pool = 兩組轉換數合計 / 兩組樣本數合計。
se = sqrt(p_pool*(1-p_pool)*(1/n_c+1/n_t))。
z = (p_t-p_c)/se。

### 雙尾顯著性與方向是不同問題

雙尾 α=0.05 使用 **ABS(未四捨五入 z)>1.96**，而非只看 z>1.96。z<-1.96 也是顯著，但代表 treatment 較差，不能視為勝出。|z|>2.58 近似對應雙尾 α=0.01。未顯著不代表已證明兩組相同。

p 值描述虛無假設成立時，資料同樣或更極端的機率，不是虛無假設為真的機率，也不是 treatment 有效的機率。

### SQLite 數學函數由建置決定

SQRT(x) 與 POWER(x,0.5) 都是 SQLite 數學函數；內建來源需要 **SQLITE_ENABLE_MATH_FUNCTIONS** 編譯選項啟用。未啟用時 POWER 並不是保證可用的替代。以課程使用的 sql.js 實跑，且不要把其他 SQLite 建置的行為當成保證。

官方依據：https://sqlite.org/lang_mathfunc.html （內建數學函數）、https://sqlite.org/compile.html#enable_math_functions （建置選項）。

本課隨附 sql.js 實跑 SQRT(0.09) 與 POWER(0.09,0.5) 都回傳 0.3，但 sqlite_compileoption_used('ENABLE_MATH_FUNCTIONS') 回傳 0。不能只憑該旗標推斷自訂建置或擴充函數的可用性，仍以實際探測為準；此處不宣稱已確認這份二進位的編譯來源。

```sql run
SELECT POWER(0.09,0.5) AS root_via_power;
```

若標準誤為零，SQLite 的除零結果是 NULL，練習規定 z_score=NULL、is_significant=0；這代表不能用此常態近似下結論，不是證明無差異。小樣本與成功/失敗次數過低需另選方法。不要未規劃地反覆偷看後提前停止，並處理多重檢定、SRM 與護欄。

> [!WARN] 顯著不等於應推廣
> 正 lift、合理的實際效益與護欄檢查都不可省略。只看 treatment 已轉換者收入，無法估計全體 ARPU、增量效益或 ROI。

> [!DIALECT] 在本地建置驗證
> 本課答案採 POWER；不同 SQLite 發行版可能提供不同函數，請以相同引擎執行而不是猜測。

### 計算各實驗的 Z-score

```sql run
WITH stats AS (
  SELECT
    test_name,
    SUM(CASE WHEN variant = 'control'   THEN converted ELSE 0 END) AS conv_c,
    SUM(CASE WHEN variant = 'treatment' THEN converted ELSE 0 END) AS conv_t,
    SUM(CASE WHEN variant = 'control'   THEN 1 ELSE 0 END)         AS n_c,
    SUM(CASE WHEN variant = 'treatment' THEN 1 ELSE 0 END)         AS n_t
  FROM ab_tests
  GROUP BY test_name
),
z AS (
  SELECT
    test_name,
    conv_c * 1.0 / n_c                             AS p1,
    conv_t * 1.0 / n_t                             AS p2,
    (conv_c + conv_t) * 1.0 / (n_c + n_t)         AS p_pool,
    n_c, n_t
  FROM stats
)
SELECT
  test_name,
  ROUND(
    (p2 - p1) / POWER(p_pool * (1 - p_pool) * (1.0/n_c + 1.0/n_t), 0.5)
  , 2) AS z_score,
  CASE WHEN ABS((p2 - p1) / POWER(p_pool * (1 - p_pool) * (1.0/n_c + 1.0/n_t), 0.5)) > 1.96
       THEN 1 ELSE 0 END AS is_significant
FROM z
ORDER BY z_score DESC, test_name ASC;
```

### 完整 A/B Test 報告（一張表呈現所有指標）

```sql run
WITH base AS (
  SELECT
    test_name,
    SUM(CASE WHEN variant='control'   THEN 1       ELSE 0 END) AS n_c,
    SUM(CASE WHEN variant='treatment' THEN 1       ELSE 0 END) AS n_t,
    SUM(CASE WHEN variant='control'   THEN converted ELSE 0 END) AS conv_c,
    SUM(CASE WHEN variant='treatment' THEN converted ELSE 0 END) AS conv_t,
    SUM(CASE WHEN variant='control'   THEN revenue ELSE 0 END) AS rev_c,
    SUM(CASE WHEN variant='treatment' THEN revenue ELSE 0 END) AS rev_t
  FROM ab_tests
  GROUP BY test_name
),
calcs AS (
  SELECT
    test_name,
    n_c, n_t,
    conv_c * 1.0 / n_c AS p_c,
    conv_t * 1.0 / n_t AS p_t,
    (conv_c + conv_t) * 1.0 / (n_c + n_t) AS p_pool,
    rev_c * 1.0 / n_c AS arpu_c,
    rev_t * 1.0 / n_t AS arpu_t
  FROM base
)
SELECT
  test_name,
  n_c                                    AS control_n,
  n_t                                    AS treatment_n,
  ROUND(p_c * 100, 2)                    AS control_cvr,
  ROUND(p_t * 100, 2)                    AS treatment_cvr,
  ROUND((p_t - p_c) / NULLIF(p_c, 0) * 100, 1)     AS relative_lift_pct,
  ROUND(arpu_c, 2)                       AS control_arpu,
  ROUND(arpu_t, 2)                       AS treatment_arpu,
  ROUND(
    (p_t - p_c) / POWER(p_pool*(1-p_pool)*(1.0/n_c+1.0/n_t), 0.5)
  , 2)                                   AS z_score,
  CASE WHEN ABS((p_t - p_c) / POWER(p_pool*(1-p_pool)*(1.0/n_c+1.0/n_t), 0.5)) > 1.96
       THEN 1 ELSE 0 END                 AS is_significant
FROM calcs
ORDER BY relative_lift_pct DESC, test_name ASC;
```

### 找出各實驗的高價值轉換用戶特徵

```sql run
SELECT
  ab.test_name,
  u.plan,
  COUNT(*)                      AS converted_users,
  ROUND(AVG(ab.revenue), 2)    AS avg_revenue
FROM ab_tests ab
JOIN users u ON u.user_id = ab.user_id
WHERE ab.variant = 'treatment'
  AND ab.converted = 1
GROUP BY ab.test_name, u.plan
ORDER BY ab.test_name, avg_revenue DESC, u.plan ASC;
```
