## 計算 A/B Test 基礎指標

A/B Test 以隨機分派比較 control 與 treatment，但先確認觀測窗、分流比例與資料品質。

CVR = 轉換數 / 全體分派用戶數。ARPU = 收入 / 全體分派用戶數，包含未轉換者，不是只看已轉換者的平均收入。

- 絕對差 = treatment CVR - control CVR，以百分點表示。
- 相對 lift = (treatment CVR - control CVR) / control CVR × 100%，負值表示 treatment 較差。
- 先用完整精度算 lift，最後才四捨五入；control CVR=0 時相對 lift 為 NULL。
- 兩種差異與不確定性都要呈現，不應刻意挑聽起來更大的數字。

> [!WARN] 固定 10% 不是分流異常門檻
> 先核對預先設定的配置比例，不一定是 50/50；依樣本量、預設顯著水準做樣本比例失配檢定（SRM）並調查追蹤/分派問題。相同人數差在大小樣本下意義不同，不能超過 10% 就斷定分流錯誤。

> [!DIALECT] SQLite 比率
> 以 100.0 或 1.0 保留浮點精度；NULLIF 處理零分母。排名同分依 test_name ASC，分組列表依題目指定的完整排序。

### 計算各實驗的 control vs treatment 轉換率

```sql run
SELECT
  test_name,
  variant,
  COUNT(*)                                  AS n,
  ROUND(SUM(converted) * 100.0 / COUNT(*), 2) AS cvr_pct
FROM ab_tests
GROUP BY test_name, variant
ORDER BY test_name, variant;
```

### 計算 Relative Lift（相對提升幅度）

```sql run
WITH cvr AS (
  SELECT
    test_name,
    variant,
    SUM(converted) * 100.0 / COUNT(*) AS cvr
  FROM ab_tests
  GROUP BY test_name, variant
)
SELECT
  ctrl.test_name,
  ROUND(ctrl.cvr, 2)                                      AS control_cvr,
  ROUND(trt.cvr, 2)                                       AS treatment_cvr,
  ROUND((trt.cvr - ctrl.cvr) / NULLIF(ctrl.cvr, 0) * 100, 1)        AS relative_lift_pct
FROM cvr ctrl
JOIN cvr trt ON trt.test_name = ctrl.test_name AND trt.variant = 'treatment'
WHERE ctrl.variant = 'control'
ORDER BY relative_lift_pct DESC, ctrl.test_name ASC;
```

### 計算各實驗的每用戶平均收入（ARPU）

```sql run
SELECT
  test_name,
  variant,
  ROUND(SUM(revenue), 2)              AS total_revenue,
  COUNT(*)                            AS n,
  ROUND(SUM(revenue) / COUNT(*), 2)  AS arpu
FROM ab_tests
GROUP BY test_name, variant
ORDER BY test_name, variant;
```
