# A/B Test 基礎指標計算

## 什麼是 A/B Test？

A/B Test 將用戶隨機分為兩組：
- **Control（對照組）**：使用現有版本
- **Treatment（實驗組）**：使用新版本

比較兩組的關鍵指標，判斷新版本是否更好。

## 本課使用的 ab_tests 表

```
test_name    | 實驗名稱（onboarding_v2 / pricing_modal / feature_discovery）
user_id      | 用戶
variant      | control 或 treatment
assigned_date| 分配日期
converted    | 是否轉換（1/0）
revenue      | 轉換收入（未轉換為 0）
```

## 計算轉換率

```sql
SELECT
  test_name,
  variant,
  COUNT(*) AS n,
  ROUND(SUM(converted) * 100.0 / COUNT(*), 2) AS cvr_pct
FROM ab_tests
GROUP BY test_name, variant
ORDER BY test_name, variant;
```

## 計算 Relative Lift

```
Absolute Lift = treatment CVR - control CVR
Relative Lift = Absolute Lift / control CVR × 100%
```

例如：control CVR = 8%，treatment CVR = 10%
- Absolute Lift = 2 個百分點
- Relative Lift = 2 / 8 × 100 = 25%

## 重要：先確認樣本數

在解讀結果前，先確認兩組樣本數相近：

```sql
SELECT test_name, variant, COUNT(*) AS n
FROM ab_tests
GROUP BY test_name, variant;
```

若兩組差距超過 10%，需要調查分流邏輯是否有問題。
