## 計算各功能的採用率

功能規劃前先確認母體。本課自訂口徑是 **當前 is_active=1 固定母體的 2025 年功能接觸率**，不是歷史 MAU 母體的採用率。

- 分母為 users 中當前 is_active=1 的人數；分方案時限制相同方案。
- 分子是該母體內在 [2025-01-01, 2026-01-01) 有指定功能事件的人數，任何 event_type 皆算接觸，不要求 daily_active 同日存在。
- is_active 是當前快照，不能證明歷史每天的活躍。分子必須是分母子集合，不能拿所有人的事件除以目前活躍者。
- 只回傳有符合事件的功能/方案組合，非所有零接觸組合。

COUNT DISTINCT 衡量接觸覆蓋；總事件數/使用者數衡量使用頻率。viewed 只是看過，不能說完成價值行為。

「看過但沒完成」練習是 (user_id, feature_name) 的集合差，不是確認先後順序的漏斗；完成其他功能不代表完成此功能。可能的 UX 或價值問題仍須訪談/實驗，不能只憑集合差診斷。方案差異也不直接證明功能導致升級。

> [!DIALECT] 邊界、排序與除法
> 本課日期為 YYYY-MM-DD，包含年起點、不含次年起點；SQLite 使用 100.0 保留小數。比例排序同分依 feature_name ASC。

### 計算各功能的整體採用率

```sql run
WITH active_base AS (
  SELECT COUNT(*) AS total_active FROM users WHERE is_active = 1
)
SELECT
  fe.feature_name,
  COUNT(DISTINCT fe.user_id)                             AS unique_users,
  ROUND(COUNT(DISTINCT fe.user_id) * 100.0
        / (SELECT total_active FROM active_base), 2)    AS adoption_pct
FROM feature_events fe
JOIN users u ON u.user_id = fe.user_id AND u.is_active = 1
WHERE fe.event_date >= '2025-01-01' AND fe.event_date < '2026-01-01'
GROUP BY fe.feature_name
ORDER BY adoption_pct DESC, fe.feature_name ASC;
```

### 各方案用戶的功能採用率差異

```sql run
WITH plan_base AS (
  SELECT plan, COUNT(*) AS plan_active_users
  FROM users
  WHERE is_active = 1
  GROUP BY plan
),
feature_adoption AS (
  SELECT
    u.plan,
    fe.feature_name,
    COUNT(DISTINCT fe.user_id) AS users_adopted
  FROM feature_events fe
  JOIN users u ON u.user_id = fe.user_id AND u.is_active = 1
  WHERE fe.event_date >= '2025-01-01' AND fe.event_date < '2026-01-01'
  GROUP BY u.plan, fe.feature_name
)
SELECT
  fa.plan,
  fa.feature_name,
  fa.users_adopted,
  pb.plan_active_users,
  ROUND(fa.users_adopted * 100.0 / pb.plan_active_users, 1) AS adoption_pct
FROM feature_adoption fa
JOIN plan_base pb ON pb.plan = fa.plan
ORDER BY fa.plan, adoption_pct DESC, fa.feature_name ASC;
```

### 找出「只看過但從未完成」的功能

```sql run
WITH viewed AS (
  SELECT DISTINCT user_id, feature_name
  FROM feature_events
  WHERE event_type = 'viewed'
),
completed AS (
  SELECT DISTINCT user_id, feature_name
  FROM feature_events
  WHERE event_type = 'completed'
)
SELECT
  v.feature_name,
  COUNT(*) AS abandoned_users
FROM viewed v
WHERE NOT EXISTS (
  SELECT 1 FROM completed c
  WHERE c.user_id = v.user_id AND c.feature_name = v.feature_name
)
GROUP BY v.feature_name
ORDER BY abandoned_users DESC, v.feature_name ASC;
```
