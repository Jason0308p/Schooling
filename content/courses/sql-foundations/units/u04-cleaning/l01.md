## 為什麼需要 CASE WHEN？

資料很少直接告訴你「這是大單還是小單」、「這個會員是高價值還是一般」。
`CASE WHEN` 讓你**在查詢裡即時打標籤、分級、轉換值**，是資料清理和報表製作最常用的工具之一。

## Searched CASE：最常用的寫法

```sql
CASE
  WHEN 條件1 THEN 結果1
  WHEN 條件2 THEN 結果2
  ELSE 預設結果
END
```

條件從上往下逐一比對，**第一個成立就停止**，不會繼續往下比。
`ELSE` 省略的話，都不符合時回傳 `NULL`。

### 範例 1：依訂單金額貼標籤

```sql run
SELECT
  order_id,
  total_amount,
  CASE
    WHEN total_amount < 1000          THEN '小單'
    WHEN total_amount BETWEEN 1000 AND 4999 THEN '中單'
    ELSE                                   '大單'
  END AS order_tier
FROM orders
WHERE status = 'completed'
LIMIT 20;
```

> [!TIP]
> `BETWEEN a AND b` 在 SQLite 是閉區間（含兩端），相當於 `>= a AND <= b`。

## Simple CASE：值對值比較

當你要把某個欄位的具體值一一對應，可以用更簡潔的 Simple CASE：

```sql
CASE 欄位
  WHEN '值A' THEN '結果A'
  WHEN '值B' THEN '結果B'
  ELSE '其他'
END
```

### 範例 2：把 membership_tier 轉成排序用的數字

```sql run
SELECT
  customer_id,
  name,
  membership_tier,
  CASE membership_tier
    WHEN '金卡' THEN 3
    WHEN '銀卡' THEN 2
    WHEN '一般' THEN 1
    ELSE 0
  END AS tier_rank
FROM customers
ORDER BY tier_rank DESC
LIMIT 20;
```

> [!BIZ]
> 把文字等級轉成數字，就能用 `ORDER BY tier_rank DESC` 從高到低排序——這是「自定義排序」的標準做法，不需要資料庫有原生的 enum 類型。

## CASE 搭配彙總函數：條件計數

`SUM(CASE WHEN ... THEN 1 ELSE 0 END)` 是**類 COUNTIF** 的寫法，等同於 Excel 的 `COUNTIF`，
可以在同一個 `GROUP BY` 查詢裡同時計算不同條件的數量。

### 範例 3：各管道的訂單狀態分佈

```sql run
SELECT
  sales_channel,
  COUNT(*)                                           AS total_orders,
  SUM(CASE WHEN status = 'completed'  THEN 1 ELSE 0 END) AS completed,
  SUM(CASE WHEN status = 'refunded'   THEN 1 ELSE 0 END) AS refunded,
  SUM(CASE WHEN status = 'cancelled'  THEN 1 ELSE 0 END) AS cancelled
FROM orders
GROUP BY sales_channel;
```

### 範例 4：CASE 在 GROUP BY——把連續值分桶再彙總

```sql run
SELECT
  CASE
    WHEN total_amount < 1000          THEN '小單'
    WHEN total_amount BETWEEN 1000 AND 4999 THEN '中單'
    ELSE                                   '大單'
  END AS order_tier,
  COUNT(*)            AS order_count,
  ROUND(SUM(total_amount)) AS tier_revenue
FROM orders
WHERE status = 'completed'
GROUP BY order_tier;
```

> [!WARN]
> 在 `GROUP BY` 裡重複貼上整段 `CASE` 運算式——這在各資料庫都能運作。有些資料庫允許 `GROUP BY order_tier`（直接用別名），但 SQLite 也支援，不過 BigQuery 不允許在 `GROUP BY` 用 `SELECT` 別名，建議習慣寫整段以保持可攜性。

## 巢狀 CASE

`THEN` 或 `ELSE` 裡可以再放一個 `CASE`，但超過兩層就難以閱讀，請優先拆成 CTE（後面單元會教）。

```sql
CASE
  WHEN gender = 'F' THEN
    CASE
      WHEN membership_tier = '金卡' THEN 'VIP女性'
      ELSE '一般女性'
    END
  ELSE '男性或未填'
END
```

> [!DIALECT]
> **SQLite**：`CASE WHEN` 語法完全支援；`BETWEEN` 是閉區間。
>
> **PostgreSQL**：語法相同；`BETWEEN` 同為閉區間；另有 `FILTER (WHERE ...)` 語法可做條件彙總（比 `CASE WHEN` 更清晰，但不通用）。
>
> **MySQL**：語法相同；另有 `IF(cond, a, b)` 函數可代替雙分支 `CASE`，但不建議在報表 SQL 使用（可讀性低）。
>
> **BigQuery**：語法相同；`GROUP BY` **不接受別名**，必須重複整段 `CASE` 運算式，或先用子查詢/CTE 包一層再 `GROUP BY`。
