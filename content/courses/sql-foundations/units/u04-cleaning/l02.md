## NULL 是什麼？為什麼特別？

`NULL` 在 SQL 代表「**不知道**」，不是空字串、不是 0，也不是 `false`。
它有三個讓初學者卡關的特性：

1. `NULL = NULL` 的結果是 `NULL`（不是 `true`）
2. `NULL + 1` 的結果是 `NULL`
3. `COUNT(欄位)` **不計入** NULL；`COUNT(*)` 計入所有列

所以要判斷某欄位是否為空，**只能用 `IS NULL` 或 `IS NOT NULL`**，不能用 `= NULL`。

## IS NULL / IS NOT NULL

```sql run
SELECT
  customer_id,
  name,
  city,
  gender
FROM customers
WHERE city IS NULL OR gender IS NULL
LIMIT 20;
```

## COALESCE：給 NULL 一個預設值

`COALESCE(a, b, c, ...)` 從左到右回傳**第一個非 NULL** 的值。
最常用的是兩個參數：`COALESCE(欄位, '預設值')`。

### 範例 1：補上缺漏的城市

```sql run
SELECT
  customer_id,
  name,
  city,
  COALESCE(city, '未填') AS display_city
FROM customers
LIMIT 20;
```

> [!TIP]
> `COALESCE` 是 SQL 標準，各大資料庫都支援，是最推薦的寫法。
> SQLite 另有 `IFNULL(a, b)`，功能等同兩個參數的 `COALESCE`，但只能放兩個參數。

## NULLIF：製造 NULL，防止除以零

`NULLIF(a, b)` 的規則：
- 若 `a = b`，回傳 `NULL`
- 否則回傳 `a`

最典型的用途是**防除以零**：`clicks / NULLIF(impressions, 0)`。
當 `impressions = 0` 時，分母變 `NULL`，整個算式結果為 `NULL`，而不是報錯。

### 範例 2：計算廣告 CTR，防除以零

```sql run
SELECT
  spend_date,
  campaign_id,
  impressions,
  clicks,
  ROUND(
    CAST(clicks AS REAL) / NULLIF(impressions, 0) * 100,
    2
  ) AS ctr
FROM ad_spend
ORDER BY spend_date, campaign_id
LIMIT 20;
```

> [!WARN]
> SQLite 預設整數相除得整數：`3 / 10 = 0`，不是 `0.3`。
> 解法：先 `CAST(欄位 AS REAL)` 或乘以 `1.0`：`clicks * 1.0 / NULLIF(impressions, 0)`。

## NULL 在運算和彙總中的行為

```sql run
SELECT
  COUNT(*)           AS total_rows,
  COUNT(coupon_code) AS rows_with_coupon,
  COUNT(*) - COUNT(coupon_code) AS null_coupon_count,
  ROUND(
    (COUNT(*) - COUNT(coupon_code)) * 100.0 / COUNT(*),
    1
  ) AS null_pct
FROM orders;
```

> [!BIZ]
> 這個查詢告訴你「有多少訂單沒有使用折扣碼」——`COUNT(欄位)` 會自動忽略 NULL，
> 用 `COUNT(*) - COUNT(欄位)` 就是 NULL 的數量。

## 找出 coupon_code 為 NULL 的訂單

```sql run
SELECT
  COUNT(*)                        AS no_coupon_orders,
  ROUND(SUM(total_amount))        AS no_coupon_revenue,
  ROUND(SUM(discount))            AS no_coupon_discount,
  ROUND(
    SUM(discount) * 100.0 / NULLIF(SUM(total_amount + discount), 0),
    2
  ) AS discount_rate_pct
FROM orders
WHERE status = 'completed'
  AND coupon_code IS NULL;
```

> [!DIALECT]
> **SQLite**：`IFNULL(a, b)` 等同兩個參數的 `COALESCE`；不支援 `NVL`（Oracle 語法）。
>
> **PostgreSQL**：有 `COALESCE`、`NULLIF`；另有 `IS DISTINCT FROM` / `IS NOT DISTINCT FROM` 處理含 NULL 的比較（`NULL IS NOT DISTINCT FROM NULL` 為 true）。
>
> **MySQL**：有 `COALESCE`、`NULLIF`；`IFNULL(a, b)` 同 SQLite。
>
> **BigQuery**：有 `COALESCE`、`NULLIF`；另有 `IFNULL` 和 `IF(cond, a, b)`；`SAFE_DIVIDE(a, b)` 可直接防除以零（b=0 時回傳 NULL），比 `NULLIF` 更語意清晰。
