## 為什麼文字需要清理？

真實資料裡，email 可能有前後空白、城市名可能有繁簡之分（「臺北市」vs「台北市」）、
日期存成字串時要取年月。字串函數讓你**在查詢時直接修正**，不需要改原始資料。

## 常用字串函數一覽

| 函數 | 用途 | 範例 |
|------|------|------|
| `TRIM(s)` | 去除前後空白 | `TRIM('  hi  ')` → `'hi'` |
| `LTRIM(s)` / `RTRIM(s)` | 去除左 / 右空白 | |
| `LOWER(s)` | 全部轉小寫 | `LOWER('ABC')` → `'abc'` |
| `UPPER(s)` | 全部轉大寫 | |
| `REPLACE(s, old, new)` | 取代子字串 | `REPLACE('臺北市', '臺', '台')` |
| `SUBSTR(s, start, len)` | 取子字串（1-indexed） | `SUBSTR('2025-07', 1, 4)` → `'2025'` |
| `LENGTH(s)` | 字串長度 | `LENGTH('hello')` → `5` |
| `INSTR(s, sub)` | 找子字串位置，找不到回傳 0 | `INSTR('abc@d.com', '@')` → `4` |

> [!WARN]
> SQLite 的 `SUBSTR` 是 **1-indexed**（第一個字元是位置 1）。
> 位置數字是負數時，從字串末尾倒數計算。

## 範例 1：清理 email

email 有前後空白或大寫字母，都可能導致比對失敗：

```sql run
SELECT
  customer_id,
  email                           AS raw_email,
  LOWER(TRIM(email))              AS cleaned_email,
  CASE WHEN email != LOWER(TRIM(email)) THEN 1 ELSE 0 END AS is_dirty
FROM customers
LIMIT 20;
```

## 範例 2：統一城市名稱

「臺北市」和「台北市」在資料庫裡是不同的字串，GROUP BY 時會變成兩列：

```sql run
SELECT
  city                                    AS original_city,
  REPLACE(
    COALESCE(city, '未知'),
    '臺北市', '台北市'
  )                                       AS clean_city,
  COUNT(*)                                AS customer_count
FROM customers
GROUP BY city
ORDER BY customer_count DESC;
```

> [!BIZ]
> 修正的順序很重要：先 `COALESCE` 把 NULL 換成預設字串，再 `REPLACE` 統一寫法。
> 反過來 `REPLACE(NULL, ...)` 還是 NULL，第二步就沒有效果。

## 範例 3：從日期字串取年月

`order_date` 存成 `YYYY-MM-DD` 的字串，用 `SUBSTR` 可以直接取前 7 個字元：

```sql run
SELECT
  SUBSTR(order_date, 1, 7)    AS month,
  COUNT(*)                    AS order_count,
  ROUND(SUM(total_amount))    AS revenue
FROM orders
WHERE status = 'completed'
GROUP BY month
ORDER BY month;
```

## LIKE 與萬用字元

`LIKE` 用於模糊比對，`%` 代表任意長度的字元，`_` 代表單一字元：

```sql run
SELECT customer_id, email
FROM customers
WHERE email LIKE '%@gmail.com'
LIMIT 10;
```

> [!DIALECT]
> **SQLite**：`LIKE` 預設**不區分大小寫**（只對 ASCII 字元）；`SUBSTR` 和 `SUBSTRING` 都支援。
>
> **PostgreSQL**：`LIKE` 區分大小寫；不分大小寫請用 `ILIKE`；字串函數有 `LEFT(s, n)`、`RIGHT(s, n)` 更直觀；`||` 運算子串接字串。
>
> **MySQL**：`LIKE` 是否區分大小寫取決於 collation；有 `LEFT`、`RIGHT`、`LOCATE` 等函數；串接用 `CONCAT()`。
>
> **BigQuery**：區分大小寫；有 `STARTS_WITH`、`ENDS_WITH`、`REGEXP_CONTAINS` 等進階函數；`SUBSTR` 和 `SUBSTRING` 均可；串接用 `||` 或 `CONCAT()`。
