# PARTITION BY：分組排名

上一課的排名是針對「整張表」。加上 `PARTITION BY`，就能在**每個分組內**獨立排名——每組的計數從 1 重新開始。

> [!BIZ]
> 「找每個分類賣最貴的商品」、「找每位客戶的第一張訂單」、「各通路當月業績排名」——這些問題都有一個共同結構：先分組，再在組內排名。`PARTITION BY` 就是解決這類問題的關鍵。

---

## PARTITION BY 語義

```sql
函數() OVER (PARTITION BY 分組欄 ORDER BY 排名欄 DESC)
```

- `PARTITION BY`：把結果集切成多個「分區」，排名在分區內獨立計算
- `ORDER BY`：決定分區內的排名依據
- **列數不變**：不像 `GROUP BY` 會壓縮列數，視窗函數保留所有原始列

### 與 GROUP BY 的關鍵差異

| | `GROUP BY` | `PARTITION BY` |
|---|---|---|
| 輸出列數 | 壓縮成一列 / 每組 | 保留所有原始列 |
| 目的 | 彙總計算 | 為每列附加統計值 |
| 能同時取原始欄位 | 受限（需 MAX 等） | 可以 |

---

## 範例 1：各分類商品依售價排名

```sql run
SELECT
  product_name,
  category,
  price,
  DENSE_RANK() OVER (
    PARTITION BY category
    ORDER BY price DESC
  ) AS cat_rank
FROM products
WHERE is_active = 1
ORDER BY category, cat_rank;
```

> [!TIP]
> 這裡選用 `DENSE_RANK()` 而非 `RANK()`，是因為同一分類中若有同價商品，`DENSE_RANK` 不會產生跳號，後續過濾 `cat_rank <= 3` 才不會遺漏名次。

## 範例 2：找每位會員的第一張 completed 訂單

```sql run
WITH first_orders AS (
  SELECT
    ROW_NUMBER() OVER (
      PARTITION BY customer_id
      ORDER BY order_date, order_id
    ) AS rn,
    order_id,
    customer_id,
    order_date,
    total_amount
  FROM orders
  WHERE status = 'completed'
)
SELECT
  customer_id,
  order_id,
  order_date,
  total_amount
FROM first_orders
WHERE rn = 1
ORDER BY customer_id
LIMIT 20;
```

> [!WARN]
> `ORDER BY order_date` 時，若同一天有多張訂單，排名會不穩定。加上 `order_id`（通常是自增主鍵）作為第二排序欄，可確保結果確定性。

## 範例 3：各銷售通路訂單按金額排名，取前 3 名

```sql run
WITH channel_ranked AS (
  SELECT
    order_id,
    customer_id,
    order_date,
    sales_channel,
    total_amount,
    RANK() OVER (
      PARTITION BY sales_channel
      ORDER BY total_amount DESC
    ) AS channel_rank
  FROM orders
  WHERE status = 'completed'
)
SELECT *
FROM channel_ranked
WHERE channel_rank <= 3
ORDER BY sales_channel, channel_rank;
```

> [!BIZ]
> 這個查詢回傳每個通路的前 3 名，允許並列（若第 2、3 名同分，兩筆都會出現，且沒有第 4 名）。如果業務需求是「剛好 3 筆」，改用 `ROW_NUMBER()`。

---

## PARTITION BY 可以多欄

```sql run
-- 按「銷售通路 + 訂單月份」分組排名
WITH monthly_channel AS (
  SELECT
    order_id,
    customer_id,
    sales_channel,
    strftime('%Y-%m', order_date) AS order_month,
    total_amount,
    ROW_NUMBER() OVER (
      PARTITION BY sales_channel, strftime('%Y-%m', order_date)
      ORDER BY total_amount DESC
    ) AS rn
  FROM orders
  WHERE status = 'completed'
)
SELECT *
FROM monthly_channel
WHERE rn = 1
ORDER BY order_month, sales_channel;
```

> [!DIALECT]
> **SQLite**：`PARTITION BY` 支援表達式，例如 `PARTITION BY strftime('%Y-%m', order_date)` 可直接使用。
> **PostgreSQL**：同樣支援表達式；另外可用 `date_trunc('month', order_date)` 截斷到月份。
> **BigQuery**：可用 `FORMAT_DATE('%Y-%m', order_date)`；支援 `QUALIFY` 子句直接過濾視窗函數結果，無需 CTE。
