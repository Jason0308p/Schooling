## GROUP BY：分組彙總

上一課的彙總把**整張表**壓成一列。如果想要「**每個**通路各自的營收」，就要先分組，再對每一組彙總。這就是 `GROUP BY`：

```sql run
SELECT
  sales_channel,
  COUNT(*)          AS order_count,
  SUM(total_amount) AS revenue
FROM orders
WHERE status = 'completed'
GROUP BY sales_channel;
```

運作方式：

1. `WHERE` 先留下已完成的訂單。
2. `GROUP BY sales_channel` 把訂單依通路分成三堆。
3. 每一堆各自算 `COUNT(*)` 和 `SUM(total_amount)`，一堆變成一列。

> [!NOTE] 這就是 Excel 的樞紐分析表
> `GROUP BY` 的欄位 = 樞紐分析表的「列」；彙總函數 = 「值」欄位裡的加總、計數、平均。學會 GROUP BY，你就能用 SQL 做出任何樞紐分析。

## GROUP BY 的鐵則

**SELECT 裡的每一個欄位，要嘛出現在 GROUP BY 裡，要嘛被彙總函數包起來。**

```sql
SELECT sales_channel, order_date, SUM(total_amount)   -- ❌ order_date 呢？
FROM orders
GROUP BY sales_channel;
```

一個通路有幾百張訂單、幾百個日期，資料庫不知道要顯示哪一個。

- PostgreSQL、BigQuery、SQL Server 會直接**報錯**。
- SQLite 和舊版 MySQL **不會報錯**，會隨便挑一個值給你。這更危險，因為你會拿到看起來正常的錯誤數字。

> [!WARN] 在 SQLite 練習時，請自己遵守這條規則
> 本課程的練習資料庫是 SQLite，它不會幫你擋下這個錯。養成習慣：寫完 GROUP BY 後，逐一檢查 SELECT 的每個欄位。

## 按月份分組：時間趨勢

報表最常見的需求是「每個月」。日期是 `'2025-12-25'` 這種文字，取前 7 個字就是 `'2025-12'`：

```sql run
SELECT
  substr(order_date, 1, 7) AS month,
  COUNT(*)                 AS order_count,
  SUM(total_amount)        AS revenue
FROM orders
WHERE status = 'completed'
GROUP BY substr(order_date, 1, 7)
ORDER BY month;
```

`substr(文字, 起始位置, 長度)` 擷取一段文字。第 4 單元會教更完整的日期函數。

> [!TIP] GROUP BY 可以用別名或位置
> SQLite、MySQL、PostgreSQL、BigQuery 都允許 `GROUP BY month`（用 SELECT 的別名）或 `GROUP BY 1`（第 1 個欄位）。`GROUP BY 1, 2` 在探索資料時很方便，但正式報表建議寫出完整欄位，比較好讀。SQL Server 兩者都不支援。

## 多個欄位分組

`GROUP BY a, b` 會依「a × b 的每種組合」分組：

```sql run
SELECT sales_channel, payment_method, COUNT(*) AS order_count
FROM orders
GROUP BY sales_channel, payment_method
ORDER BY sales_channel, order_count DESC;
```

> [!DIALECT] BigQuery 的日期分組
> 在 BigQuery 中日期通常是 `DATE` 型別，月份分組會寫成 `DATE_TRUNC(order_date, MONTH)` 或 `FORMAT_DATE('%Y-%m', order_date)`。PostgreSQL 是 `DATE_TRUNC('month', order_date)`，MySQL 是 `DATE_FORMAT(order_date, '%Y-%m')`。概念完全一樣，只是函數名稱不同。
