# L01：上個月營收為什麼掉了？

> 分析週期性落差時，永遠先問「整體掉了多少」，再問「哪裡掉的」。

---

## 主管需求

> 「2026 年 5 月的 completed 訂單營收比 4 月少，你去查一下是哪個通路掉的？」

收到這個需求，先別急著下手。問自己三個問題：

1. 「少」是多少？降幅 1% 和 30% 需要完全不同的回應。
2. 是全面下滑，還是局部通路？
3. 是訂單數少了，還是客單價降了？

---

## 分析思路

```
整體 → 拆通路 → 找異常 → 算環比
```

先確認「總數字是否真的掉了」，排除資料問題。再按 `sales_channel` 分組，找出貢獻最大的下滑來源。最後用環比（月對月）量化每個通路的變化。

---

## 步驟一：先看整體月營收

```sql run
SELECT
  SUBSTR(order_date, 1, 7) AS month,
  COUNT(*)                  AS order_count,
  ROUND(SUM(total_amount))  AS revenue
FROM orders
WHERE status = 'completed'
  AND order_date >= '2026-04-01'
  AND order_date <  '2026-06-01'
GROUP BY month
ORDER BY month;
```

> [!BIZ]
> 先確認整體數字，才有比較基準。如果總量本來就有季節性落差（例如母親節在 5 月初就採購完畢），掉 5% 可能完全正常。

---

## 步驟二：拆分通路

```sql run
SELECT
  CASE
    WHEN order_date LIKE '2026-04%' THEN '2026-04'
    WHEN order_date LIKE '2026-05%' THEN '2026-05'
  END                         AS month,
  sales_channel,
  COUNT(*)                    AS order_count,
  ROUND(SUM(total_amount))    AS revenue
FROM orders
WHERE status = 'completed'
  AND order_date >= '2026-04-01'
  AND order_date <  '2026-06-01'
GROUP BY month, sales_channel
ORDER BY month ASC, revenue DESC;
```

現在我們能看到每個通路在兩個月的表現，但比較還不夠直覺。

---

## 步驟三：計算環比（用 CTE + self-join）

```sql run
WITH monthly AS (
  SELECT
    CASE
      WHEN order_date LIKE '2026-04%' THEN '2026-04'
      WHEN order_date LIKE '2026-05%' THEN '2026-05'
    END                       AS month,
    sales_channel,
    ROUND(SUM(total_amount))  AS revenue
  FROM orders
  WHERE status = 'completed'
    AND order_date >= '2026-04-01'
    AND order_date <  '2026-06-01'
  GROUP BY month, sales_channel
)
SELECT
  m5.sales_channel,
  m4.revenue  AS apr_revenue,
  m5.revenue  AS may_revenue,
  m5.revenue - m4.revenue                                   AS revenue_change,
  ROUND((m5.revenue - m4.revenue) * 100.0 / m4.revenue, 1) AS growth_pct
FROM       monthly m5
JOIN       monthly m4
  ON  m5.sales_channel = m4.sales_channel
  AND m4.month = '2026-04'
  AND m5.month = '2026-05'
ORDER BY revenue_change ASC;
```

> [!BIZ]
> `revenue_change ASC` 把下滑最多的通路排在最前面，讓主管第一眼就看到重點。負數 `growth_pct` 代表環比下滑。

---

## 結論怎麼說

不要只說「B2B 通路掉了」，要給數字和比率：

> 「2026 年 5 月 B2B 通路 completed 訂單數從 412 降至 289（-29.9%），是當月整體營收下滑的主因，佔總降幅的 67%。建議確認 B2B 客戶是否有集中到期或被競品搶單的情況。」

---

## 小結

| 工具 | 用途 |
|------|------|
| `CASE WHEN order_date LIKE ...` | 動態產生月份欄位 |
| CTE + self-join | 在同一查詢中比較兩個月 |
| `revenue_change`, `growth_pct` | 量化環比變化 |
| `ORDER BY revenue_change ASC` | 把問題排在最前 |
