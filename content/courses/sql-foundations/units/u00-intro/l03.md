## 練習系統怎麼運作

每一課的後半段都有練習題。每一題都是一個**工作情境**：誰在跟你要資料、為什麼要。你要寫出 SQL 交出他要的結果。

每題有四個按鈕：

| 按鈕 | 快捷鍵 | 作用 |
|---|---|---|
| **執行** | `Ctrl + Enter` | 跑你的 SQL，看結果長怎樣，不算分 |
| **送出答案** | `Ctrl + Shift + Enter` | 批改，判斷對錯 |
| **提示** | | 一次給一個提示，從方向到具體寫法 |
| **看解答** | | 顯示標準答案和解說（會記錄你看過解答） |

## 批改的規則

系統**比對的是查詢結果，不是你打的字**：

- 你的寫法跟標準答案不同沒關係，結果一樣就算對。
- 欄位**別名**（AS 後面取的名字）不影響對錯。
- 除非題目有要求排序，否則**列的順序**不影響對錯。
- 數字會先四捨五入到小數第 2 位再比，所以浮點數的小誤差不會被誤判。
- **欄位的數量和順序**要照題目寫的給。順序不同但內容對，會判對並提醒你。

答錯時，系統會告訴你錯在哪一類：欄位數不對、筆數不對、數值不同、還是排序不對。也會列出**預期結果**讓你比對。

> [!TIP] 先執行，再送出
> 養成習慣：先按「執行」看結果，自己判斷數字合不合理，再按「送出」。這就是實際工作的流程，因為主管不會幫你批改。

## 寫 SQL 的書寫慣例

SQL 對關鍵字的大小寫不敏感，`select` 和 `SELECT` 都可以。但業界慣例是這樣寫：

```sql
-- 這是註解：兩個減號後面的文字不會被執行
SELECT product_name, price      -- 關鍵字大寫，欄位小寫
FROM products
WHERE category = '保溫杯'       -- 文字值用單引號
ORDER BY price DESC;            -- 分號代表一句結束
```

- **關鍵字大寫**、表名和欄位名小寫，一眼就看得出結構。
- **每個子句換一行**：SELECT、FROM、WHERE 各一行，查詢變長也不會亂。
- **文字值用英文單引號** `'...'`。雙引號在標準 SQL 是用來包欄位名稱的。
- 用 `--` 寫註解，說明「為什麼這樣篩選」，三個月後的自己會感謝你。

> [!WARN] 全形符號
> 中文輸入法很容易打出全形的 `，` `（` `＝` `’`。SQL 只認半形符號。看到「unrecognized token」錯誤，第一個先檢查這個。
