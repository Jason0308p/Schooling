## 為什麼要學 SQL

你在工作上看到的數字，例如 GA4 的轉換率、Shopify 後台的營收、廣告後台的 ROAS，背後都是**存在資料庫裡的一筆一筆原始資料**，被某個查詢算出來的結果。

後台報表只會給你它設計好的那幾種切法。主管一問「金卡會員在 LINE 商店的回購率是多少？」，後台沒有這張報表，你就只能匯出 Excel 慢慢拉。

**SQL（Structured Query Language）是直接跟資料庫要資料的語言。**學會之後，任何切法你都能自己算，幾秒鐘就有答案。

## 資料庫長什麼樣子

把資料庫想成一本 Excel 活頁簿，但規矩比 Excel 嚴格得多：

| Excel 的說法 | 資料庫的說法 | 說明 |
|---|---|---|
| 整個活頁簿 | 資料庫（database） | 一整個系統的資料 |
| 一張工作表 | 資料表（table） | 一種東西一張表，例如「會員」「訂單」 |
| 一列 | 列（row / record） | 一筆資料，例如一位會員 |
| 一欄 | 欄位（column / field） | 一種屬性，例如 email、註冊日 |

跟 Excel 最大的不同：

- **每一欄的資料型態是固定的。**價格欄只能放數字，不會有人在裡面打「約 500」。
- **每張表通常有一個主鍵（Primary Key）**，能唯一識別每一列，例如 `customer_id`。
- **表和表之間靠「鍵」關聯**，而不是把所有資料塞在同一張大表。

## 你的第一個查詢

下面這段 SQL 的意思是：「從 `products`（商品）資料表，把所有欄位（`*`）都拿出來，只要前 5 筆。」按「執行」看看結果：

```sql run
SELECT * FROM products LIMIT 5;
```

這段 SQL 分成三個部分：

- `SELECT *`：要拿哪些欄位，`*` 代表全部。
- `FROM products`：從哪張表拿。
- `LIMIT 5`：最多只要 5 筆。

> [!NOTE] SQL 是「說你要什麼」，不是「說怎麼做」
> 你不用告訴資料庫要怎麼去硬碟找資料、用什麼順序讀。你只描述**想要的結果**，資料庫自己決定最快的拿法。這叫做「宣告式語言」，也是 SQL 好上手的原因。

## SQL、MySQL、PostgreSQL、BigQuery 是什麼關係

很多人第一次學都會搞混：

- **SQL** 是語言的名字，有國際標準。
- **MySQL、PostgreSQL、SQLite、SQL Server** 是資料庫軟體，各自實作 SQL，再加上自己的擴充。
- **BigQuery** 是 Google 的雲端資料倉儲，也用 SQL 查詢。GA4 的原始資料匯出就是放在 BigQuery。

它們的關係就像「中文」跟「台灣腔、北京腔、香港腔」：**核心大約八成一樣**，差別在日期函數、字串函數、一些進階語法。

本課程的練習資料庫是 **SQLite**，直接在你的瀏覽器裡執行，不用安裝任何東西。每一課如果有跟其他資料庫不一樣的地方，會用「方言差異」框特別標出來。

> [!DIALECT] 本課程的寫法在其他資料庫能用嗎？
> 第 0～3 單元的語法（SELECT、WHERE、GROUP BY、JOIN）在 MySQL、PostgreSQL、BigQuery **幾乎完全通用**。差異主要出現在第 4 單元的日期與字串函數，到時會逐一對照。
