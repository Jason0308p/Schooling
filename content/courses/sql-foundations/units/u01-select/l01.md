## 只選需要的欄位

上一單元用 `SELECT *` 拿全部欄位。實際工作中，你通常只需要其中幾個欄位，這時就把欄位名稱列出來，用逗號隔開：

```sql run
SELECT product_name, category, price
FROM products;
```

結果的欄位順序會跟你寫的順序一樣。

> [!BIZ] 為什麼實務上少用 SELECT *
> - **花錢**：BigQuery 依「掃描的欄位資料量」計費，`SELECT *` 掃全部欄位。GA4 的 events 表有幾十個欄位，差距可能是幾十倍。
> - **慢**：欄位越多，傳輸越慢。
> - **會壞**：別人在表裡新增欄位後，你的報表或程式可能因為多了一欄而出錯。
>
> 探索資料時用 `SELECT * ... LIMIT 10` 沒問題，正式的報表查詢請明確列出欄位。

## 計算欄位

SELECT 不只能拿現成的欄位，還能直接算數學：

```sql run
SELECT product_name, price, cost, price - cost
FROM products;
```

可以用 `+ - * /` 四則運算，也可以用括號控制先後順序。

## 用 AS 取別名

上面那欄的名稱會顯示成 `price - cost`，不好讀。用 `AS` 幫欄位取一個名字：

```sql run
SELECT
  product_name,
  price,
  cost,
  price - cost AS gross_profit
FROM products;
```

- 別名建議用**英文小寫加底線**（snake_case），例如 `gross_profit`、`order_count`。
- 如果一定要用中文或含空白的別名，要用**雙引號**包起來：`price - cost AS "毛利"`。
- `AS` 可以省略（`price - cost gross_profit` 也行），但寫出來比較清楚。

## 陷阱：整數除法

算毛利率時，直覺會這樣寫：

```sql run
SELECT product_name, (price - cost) / price AS margin
FROM products;
```

結果全部是 **0**！因為 `price` 和 `cost` 都是整數，在 SQLite（以及 PostgreSQL、SQL Server）裡，**整數除以整數，結果會捨去小數**，0.52 就變成 0。

解法是讓其中一邊變成小數。最簡單的寫法是乘上 `100.0`（注意有 `.0`）：

```sql run
SELECT
  product_name,
  ROUND((price - cost) * 100.0 / price, 1) AS margin_pct
FROM products;
```

`ROUND(數值, 小數位數)` 會四捨五入到你要的位數。

> [!DIALECT] 不同資料庫的除法
> | 資料庫 | `7 / 2` 的結果 |
> |---|---|
> | SQLite、PostgreSQL、SQL Server | `3`（整數除法） |
> | MySQL | `3.5000` |
> | BigQuery | `3.5`（`/` 一律回傳小數；要整數除法用 `DIV(7, 2)`） |
>
> 只要記得「**比例類的計算乘上 100.0 或 1.0**」，在每個資料庫都會是對的。BigQuery 另外有 `SAFE_DIVIDE(a, b)`，分母是 0 時會回傳 NULL，不會報錯。

## 文字串接

`||` 可以把文字接起來：

```sql run
SELECT sku || ' - ' || product_name AS label
FROM products
LIMIT 5;
```

> [!DIALECT] 文字串接
> SQLite、PostgreSQL、BigQuery 都可以用 `||`。MySQL 預設要用 `CONCAT(a, b, c)`；`CONCAT` 在 PostgreSQL 和 BigQuery 也能用，想寫一次到處通用就用 `CONCAT`。
