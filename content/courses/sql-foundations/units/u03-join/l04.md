## JOIN 是「橫向」接，UNION 是「縱向」疊

| | JOIN | UNION |
|---|---|---|
| 方向 | 橫向：把**欄位**接在一起 | 縱向：把**列**疊在一起 |
| 條件 | 用 ON 比對鍵 | 不比對，直接疊 |
| 用途 | 一筆資料的資訊散在多張表 | 把兩份**結構相同**的結果合併 |

## UNION ALL：直接疊起來

```sql run
SELECT 'b2b' AS segment, COUNT(*) AS orders
FROM orders
WHERE status = 'completed' AND sales_channel = 'b2b'

UNION ALL

SELECT 'b2c' AS segment, COUNT(*) AS orders
FROM orders
WHERE status = 'completed' AND sales_channel <> 'b2b';
```

這是報表裡很常見的寫法：**每一段各自算一個查詢，再疊成一張表**。注意第一欄 `'b2b'` 是我們自己寫的「標籤欄」，用來標示每一列代表哪一段。

## 規則

1. 每個 SELECT 的**欄位數量**要一樣。
2. 對應位置的欄位**型態要相容**（文字對文字、數字對數字）。
3. 結果的**欄位名稱以第一個 SELECT 為準**。
4. `ORDER BY` 只能寫在**最後面**，作用在整個合併結果。

```sql run
SELECT customer_id, 'gold_member' AS reason
FROM customers
WHERE membership_tier = '金卡'

UNION ALL

SELECT customer_id, 'recent_buyer' AS reason
FROM orders
WHERE status = 'completed' AND order_date >= '2026-06-01'

ORDER BY customer_id
LIMIT 10;
```

## UNION 與 UNION ALL 的差別

| | 行為 | 速度 |
|---|---|---|
| `UNION ALL` | 全部保留，**重複的列也留著** | 快 |
| `UNION` | 合併後**去除完全重複的列** | 慢（要比對去重） |

要建立「不重複的名單」時用 `UNION`：

```sql run
SELECT customer_id
FROM customers
WHERE membership_tier = '金卡'

UNION

SELECT customer_id
FROM orders
WHERE status = 'completed' AND order_date >= '2026-04-01';
```

一位既是金卡、近期又有購買的會員，在這份名單裡**只會出現一次**。如果換成 `UNION ALL`，他會出現兩次。

> [!TIP] 怎麼選
> - 確定兩邊不會有重複，或本來就想保留重複（例如分段報表）→ **`UNION ALL`**，比較快，也比較不會誤刪。
> - 要的是「不重複的名單」→ **`UNION`**。
> - 不確定時先用 `UNION ALL`，再用 `COUNT(*)` 和 `COUNT(DISTINCT ...)` 比一下有沒有重複。

> [!WARN] UNION 會悄悄去重，數字可能少算
> 兩段報表各有一列 `('b2b', 100)`，用 `UNION` 合併會被當成重複**刪掉一列**。分段報表請一律用 `UNION ALL`。

> [!DIALECT] BigQuery 一定要寫清楚
> BigQuery **不接受單獨的 `UNION`**，必須明確寫 `UNION ALL` 或 `UNION DISTINCT`。SQLite、PostgreSQL、MySQL 單寫 `UNION` 等於 `UNION DISTINCT`。習慣上都寫清楚是哪一種，跨資料庫就不會出錯。

## 單元 3 總結

| 需求 | 工具 |
|---|---|
| 把兩張表的欄位接起來，只要兩邊都有的 | `JOIN`（INNER） |
| 保留左表全部，找「沒有對到的」 | `LEFT JOIN ... WHERE 右表主鍵 IS NULL` |
| LEFT JOIN 後，右表的篩選條件 | 放 `ON`，不放 `WHERE` |
| LEFT JOIN 後數筆數 | `COUNT(右表主鍵)`，不是 `COUNT(*)` |
| JOIN 之後金額變大 | 一對多重複計算，只加總同一層的金額欄位 |
| 數「有幾張單、幾個人」 | `COUNT(DISTINCT ...)` |
| 兩份結構相同的結果疊在一起 | `UNION ALL` / `UNION` |
