## 月 Cohort 留存分析：追蹤顧客的長期忠誠度

Cohort 留存分析（Cohort Retention Analysis）追蹤「同一批人」隨時間的回購行為。它回答了一個根本問題：**我們吸引來的顧客，有多少在第一個月、第二個月、第三個月後仍然回來購買？**

> [!BIZ]
> 好禮客製每個月都有新顧客加入。Cohort 分析讓我們了解：2025 年 7 月首購的顧客，他們的留存率如何？和 2025 年 10 月首購的顧客相比，哪一批留存更好？這直接反映了顧客體驗和品牌黏著度。

## 核心概念：Cohort、Month Diff

- **Cohort**：依首購月份分組的客戶群體
- **Month Diff**：從首購月開始計算的第幾個月（0 = 首購月本身）
- **留存**：在 Month Diff = N 時，仍有 completed 訂單的不重複 customer_id 數

## 計算每位會員的首購月份

```sql run
SELECT
  customer_id,
  MIN(order_date)                         AS first_order_date,
  strftime('%Y-%m', MIN(order_date))      AS cohort_month
FROM orders
WHERE status = 'completed'
GROUP BY customer_id
ORDER BY first_order_date
LIMIT 10;
```

## 計算月差（months since first purchase）

SQLite 沒有直接的月差函數，用以下公式計算：

```sql run
WITH first_orders AS (
  SELECT
    customer_id,
    MIN(order_date) AS first_order_date,
    strftime('%Y-%m', MIN(order_date)) AS cohort_month
  FROM orders
  WHERE status = 'completed'
  GROUP BY customer_id
),
all_orders AS (
  SELECT DISTINCT
    o.customer_id,
    strftime('%Y-%m', o.order_date) AS order_month
  FROM orders o
  WHERE o.status = 'completed'
)
SELECT
  f.cohort_month,
  a.order_month,
  (
    (CAST(strftime('%Y', a.order_month || '-01') AS INTEGER) -
     CAST(strftime('%Y', f.first_order_date)    AS INTEGER)) * 12
    +
    (CAST(strftime('%m', a.order_month || '-01') AS INTEGER) -
     CAST(strftime('%m', f.first_order_date)    AS INTEGER))
  ) AS month_diff
FROM first_orders f
JOIN all_orders a ON f.customer_id = a.customer_id
LIMIT 15;
```

> [!TIP]
> 月差公式：`(年差 × 12) + 月差`。注意 `strftime('%Y-%m')` 只有年月，加上 `-01` 才能用 `strftime` 繼續解析。

> [!DIALECT]
> PostgreSQL 有 `DATE_PART('month', age(date1, date2))` 更直觀。MySQL 有 `TIMESTAMPDIFF(MONTH, d1, d2)`。SQLite 需要手動計算，但邏輯是一樣的。

> [!WARN]
> Cohort 分析的資料量可能很大：N 個 cohort × M 個月差 × K 個會員。先用 CTE 分層計算，避免一次做過多的笛卡兒積。
