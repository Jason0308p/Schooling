## 廣告 ROAS 分析：花了多少錢，賺回多少？

ROAS（Return on Ad Spend，廣告投資報酬率）是數位行銷最重要的效益指標：

$$\text{ROAS} = \frac{\text{廣告帶來的營收}}{\text{廣告花費}}$$

ROAS = 3 表示每花 1 元廣告費，帶來 3 元營收。**業界普遍將 3 視為基本及格線。**

> [!BIZ]
> 好禮客製在 Google Ads、Meta Ads、LINE 和 Email 都有投放廣告活動。行銷主管想知道：哪個 campaign 的 ROAS 最高？哪個在燒錢卻沒帶來訂單？

## 資料鏈路：廣告 → Session → 訂單

分析廣告效益的關鍵在於串聯資料：

```
campaigns → ad_spend（花費）
campaigns → sessions → orders（帶來的營收）
```

`sessions` 資料表的 `campaign_id` 欄位記錄了「這個 session 是從哪個廣告活動進來的」。

## 各活動的廣告花費

```sql run
SELECT
  a.campaign_id,
  c.campaign_name,
  c.platform,
  ROUND(SUM(a.cost)) AS total_cost
FROM ad_spend a
JOIN campaigns c ON a.campaign_id = c.campaign_id
GROUP BY a.campaign_id, c.campaign_name, c.platform
ORDER BY total_cost DESC;
```

## 各活動帶來的訂單數和營收

透過 `sessions` 將廣告活動與訂單串接。注意：訂單日期應 >= session 開始時間（因果關係）：

```sql run
SELECT
  s.campaign_id,
  COUNT(DISTINCT o.order_id)  AS attributed_orders,
  ROUND(SUM(o.total_amount))  AS attributed_revenue
FROM sessions s
JOIN orders o
  ON  o.customer_id = s.customer_id
  AND o.order_date >= DATE(s.session_start)
  AND o.status = 'completed'
WHERE s.campaign_id IS NOT NULL
GROUP BY s.campaign_id
ORDER BY attributed_revenue DESC;
```

> [!WARN]
> 廣告歸因（Attribution）有許多模型，這裡用的是「最後點擊」的簡化版本。實務上同一個 customer_id 可能有多個來自不同 campaign 的 session，這種計算方式會有重複計算的問題。此處為學習用途採用簡化模型。

## 合併計算 ROAS

```sql run
WITH spend AS (
  SELECT
    a.campaign_id,
    c.campaign_name,
    c.platform,
    ROUND(SUM(a.cost)) AS total_cost
  FROM ad_spend a
  JOIN campaigns c ON a.campaign_id = c.campaign_id
  GROUP BY a.campaign_id, c.campaign_name, c.platform
),
revenue AS (
  SELECT
    s.campaign_id,
    COUNT(DISTINCT o.order_id)  AS attributed_orders,
    ROUND(SUM(o.total_amount))  AS attributed_revenue
  FROM sessions s
  JOIN orders o
    ON  o.customer_id = s.customer_id
    AND o.order_date >= DATE(s.session_start)
    AND o.status = 'completed'
  WHERE s.campaign_id IS NOT NULL
  GROUP BY s.campaign_id
)
SELECT
  sp.campaign_name,
  sp.platform,
  sp.total_cost,
  COALESCE(rv.attributed_revenue, 0) AS attributed_revenue,
  ROUND(rv.attributed_revenue / NULLIF(sp.total_cost, 0), 2) AS roas
FROM spend sp
LEFT JOIN revenue rv ON sp.campaign_id = rv.campaign_id
WHERE sp.total_cost > 0
ORDER BY roas DESC NULLS LAST;
```

> [!TIP]
> `NULLIF(total_cost, 0)` 讓分母為零時回傳 NULL，避免除以零錯誤。`NULLS LAST` 確保 ROAS 無法計算的活動排在最後。

> [!DIALECT]
> `NULLS LAST` 在 SQLite、PostgreSQL、MySQL 8+ 均支援。若用較舊的 MySQL，可用 `ORDER BY roas IS NULL, roas DESC` 達到相同效果。
