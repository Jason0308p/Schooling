## 新客 vs 回購客：用視窗函數識別購買行為

新客和回購客對業績的貢獻性質完全不同。新客代表市場拓展，回購客代表品牌忠誠度。行銷分析師需要能快速區分這兩種客群。

> [!BIZ]
> 好禮客製希望了解：每個月的營收中，有多少來自首次購買的新顧客，多少來自已回頭的老顧客？這個比例直接影響廣告投放策略的規劃。

## 找出每位會員的第一筆訂單

核心技巧是使用 `ROW_NUMBER()` 視窗函數，依 `customer_id` 分組、依 `order_date` 排序：

```sql run
SELECT
  customer_id,
  order_id,
  order_date,
  total_amount,
  ROW_NUMBER() OVER (
    PARTITION BY customer_id
    ORDER BY order_date
  ) AS rn
FROM orders
WHERE status = 'completed'
LIMIT 20;
```

當 `rn = 1` 時，就是該客戶的首購訂單。

## 標記新客與回購客

用 CTE 將首購標記出來，再用 `CASE` 貼標籤：

```sql run
WITH ranked AS (
  SELECT
    customer_id,
    order_id,
    order_date,
    total_amount,
    ROW_NUMBER() OVER (
      PARTITION BY customer_id
      ORDER BY order_date
    ) AS rn
  FROM orders
  WHERE status = 'completed'
)
SELECT
  order_id,
  customer_id,
  order_date,
  total_amount,
  CASE WHEN rn = 1 THEN '新客' ELSE '回購' END AS customer_type
FROM ranked
LIMIT 20;
```

> [!TIP]
> `ROW_NUMBER()` 遇到同日多筆訂單時，會任意指定哪筆是第一筆。若業務邏輯要求精確，可在 `ORDER BY` 加上 `order_id` 作為決勝條件。

## 統計各類型的訂單數和營收

```sql run
WITH ranked AS (
  SELECT
    customer_id,
    order_id,
    order_date,
    total_amount,
    ROW_NUMBER() OVER (
      PARTITION BY customer_id
      ORDER BY order_date
    ) AS rn
  FROM orders
  WHERE status = 'completed'
),
labeled AS (
  SELECT
    strftime('%Y-%m', order_date) AS month,
    CASE WHEN rn = 1 THEN '新客' ELSE '回購' END AS customer_type,
    total_amount
  FROM ranked
)
SELECT
  month,
  customer_type,
  COUNT(*) AS order_count,
  ROUND(SUM(total_amount)) AS revenue
FROM labeled
GROUP BY month, customer_type
ORDER BY month, customer_type;
```

> [!WARN]
> 分析新客時，一定要先篩選 `status = 'completed'`。退款或取消的訂單不代表真正的首購行為，否則會錯誤地把後來的購買判定為「新客」。
