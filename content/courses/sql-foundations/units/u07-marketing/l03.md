## RFM 客戶分群：電商最經典的客戶價值模型

RFM 是行銷分析中最廣泛使用的客戶分群框架：

| 指標 | 全名 | 計算方式 | 越好的方向 |
|---|---|---|---|
| **R**ecency | 最近購買距今天數 | 今天 - 最後購買日 | 越小越好 |
| **F**requency | 購買頻次 | completed 訂單數 | 越大越好 |
| **M**onetary | 總消費金額 | SUM(total_amount) | 越大越好 |

> [!BIZ]
> 好禮客製有大量會員，但不是每位會員的價值都相同。RFM 分群讓行銷團隊能針對不同群體設計對應策略：對 VIP 給予專屬優惠、對沉睡客戶發送喚醒郵件。

## 計算每位會員的 R、F、M

以 `2026-06-30` 為分析基準日（資料期間最後一天）：

```sql run
SELECT
  customer_id,
  CAST(julianday('2026-06-30') - julianday(MAX(order_date)) AS INTEGER) AS recency,
  COUNT(DISTINCT order_id) AS frequency,
  ROUND(SUM(total_amount)) AS monetary
FROM orders
WHERE status = 'completed'
GROUP BY customer_id
ORDER BY monetary DESC
LIMIT 10;
```

> [!TIP]
> `julianday()` 回傳浮點數（儒略日），兩個日期相減就是天數差。`CAST(... AS INTEGER)` 去除小數點，讓天數更直覺。

## 用 CASE 加分群標籤

先用 CTE 算出 RFM，再用 `CASE WHEN` 依規則貼標籤：

```sql run
WITH rfm AS (
  SELECT
    customer_id,
    CAST(julianday('2026-06-30') - julianday(MAX(order_date)) AS INTEGER) AS recency,
    COUNT(DISTINCT order_id) AS frequency,
    ROUND(SUM(total_amount)) AS monetary
  FROM orders
  WHERE status = 'completed'
  GROUP BY customer_id
)
SELECT
  customer_id,
  recency,
  frequency,
  monetary,
  CASE
    WHEN frequency >= 5 AND monetary >= 10000 THEN 'VIP'
    WHEN frequency >= 3 OR  monetary >= 5000  THEN '活躍'
    WHEN recency <= 180                        THEN '沉睡'
    ELSE '其他'
  END AS segment
FROM rfm
ORDER BY monetary DESC
LIMIT 15;
```

> [!WARN]
> `CASE WHEN` 是依序比對，第一個符合的條件就會停止。VIP 條件放最前面，確保高頻高消費的客戶不會被誤判成「活躍」。

## 各群人數與平均消費

```sql run
WITH rfm AS (
  SELECT
    customer_id,
    CAST(julianday('2026-06-30') - julianday(MAX(order_date)) AS INTEGER) AS recency,
    COUNT(DISTINCT order_id) AS frequency,
    ROUND(SUM(total_amount)) AS monetary
  FROM orders
  WHERE status = 'completed'
  GROUP BY customer_id
),
segmented AS (
  SELECT
    customer_id,
    monetary,
    CASE
      WHEN frequency >= 5 AND monetary >= 10000 THEN 'VIP'
      WHEN frequency >= 3 OR  monetary >= 5000  THEN '活躍'
      WHEN recency <= 180                        THEN '沉睡'
      ELSE '其他'
    END AS segment
  FROM rfm
)
SELECT
  segment,
  COUNT(*) AS customer_count,
  ROUND(AVG(monetary)) AS avg_monetary
FROM segmented
GROUP BY segment
ORDER BY customer_count DESC;
```

> [!DIALECT]
> SQLite 沒有內建的 `NTILE()` 分位數分群（部分資料庫支援），所以這裡用明確的 `CASE WHEN` 條件。若要更自動化的 RFM 評分，可先用子查詢計算百分位數閾值，再套用分群。
