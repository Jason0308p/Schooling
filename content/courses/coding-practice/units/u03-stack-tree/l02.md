## 為什麼要練這題

公司通知系統的組織節點 {name, children}；要依層級由上到下、同層由左到右列出姓名。範例根 A 的子節點為 B、C，B 的子節點為 D。

> [!NOTE] 練習方式
> Schooling 目前不批改任意程式碼。下方是引導式實作與乾跑，頁面只對四選一自檢題提供即時回饋；請自行在本機執行程式並測試邊界。這裡的「Easy起步」是課程名稱，不代表與任何題庫的難度標籤等價。

## 先釐清規格，再寫解法

先口述輸入、輸出與失敗時的回傳值；有歧義就先詢問面試官。以下是此情境的一種 JavaScript 參考寫法，不是要求背誦的唯一答案。

```js
function levelNames(root) {
  if (root == null) return [];
  const queue = [root], result = [];
  for (let head = 0; head < queue.length; head++) {
    const node = queue[head];
    result.push(node.name);
    for (const child of node.children) queue.push(child);
  }
  return result;
}
```

### 手動乾跑

佇列初始 [A]；處理 A 後為 [A,B,C]；處理 B 後附加 D；接著 C、D，輸出 [A,B,C,D]。head 是讀取位置，不用 shift 反覆搬移元素。

### 邊界與複雜度

- 邊界：空根節點回傳 []；單節點回傳自身；此題假設是真正的樹、每個節點有 children 陣列，若是圖且有循環須額外用 visited。
- 複雜度：時間 O(n)，額外空間 O(n)（佇列與輸出）；n 是節點數。

> [!TIP] 面試溝通
> 先確認同層順序與空根節點；說明 BFS 依加入順序處理下一層，若題目改為分層陣列須在每層開始記下當時佇列邊界。
