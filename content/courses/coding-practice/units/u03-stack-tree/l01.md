## 為什麼要練這題

編輯器只接受 ()、[]、{} 六種字元；檢查字串 "{[()]}" 是否配對，回傳布林值。

> [!NOTE] 練習方式
> Schooling 目前不批改任意程式碼。下方是引導式實作與乾跑，頁面只對四選一自檢題提供即時回饋；請自行在本機執行程式並測試邊界。這裡的「Easy起步」是課程名稱，不代表與任何題庫的難度標籤等價。

## 先釐清規格，再寫解法

先口述輸入、輸出與失敗時的回傳值；有歧義就先詢問面試官。以下是此情境的一種 JavaScript 參考寫法，不是要求背誦的唯一答案。

```js
function balanced(text) {
  const openFor = { ")": "(", "]": "[", "}": "{" };
  const stack = [];
  for (const ch of text) {
    if (ch === "(" || ch === "[" || ch === "{") stack.push(ch);
    else if (stack.pop() !== openFor[ch]) return false;
  }
  return stack.length === 0;
}
```

### 手動乾跑

讀 {、[、( 時堆疊為 [{, [, (]；接著 )、]、} 各彈出相應開括號，最後堆疊為空，回傳 true。

### 邊界與複雜度

- 邊界：空字串視為有效；")(" 立即失敗；"((" 結尾仍有殘留而失敗；若輸入含其他字元，需先與面試官約定忽略或拒絕，本題只允許六種字元。
- 複雜度：時間 O(n)，額外空間 O(n)。

> [!TIP] 面試溝通
> 用「堆疊頂端是最近尚未配對的開括號」作為不變量，示範第一個不符位置，不只說最後數量相等。
