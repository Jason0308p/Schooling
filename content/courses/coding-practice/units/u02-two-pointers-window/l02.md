## 為什麼要練這題

監控每分鐘負載 [2,1,3,2]，找總負載不超過 5 的最長連續分鐘數；負載皆為非負整數。

> [!NOTE] 練習方式
> Schooling 目前不批改任意程式碼。下方是引導式實作與乾跑，頁面只對四選一自檢題提供即時回饋；請自行在本機執行程式並測試邊界。這裡的「Easy起步」是課程名稱，不代表與任何題庫的難度標籤等價。

## 先釐清規格，再寫解法

先口述輸入、輸出與失敗時的回傳值；有歧義就先詢問面試官。以下是此情境的一種 JavaScript 參考寫法，不是要求背誦的唯一答案。

```js
function longestWithin(loads, limit) {
  let left = 0, sum = 0, best = 0;
  for (let right = 0; right < loads.length; right++) {
    sum += loads[right];
    while (sum > limit) sum -= loads[left++];
    best = Math.max(best, right - left + 1);
  }
  return best;
}
```

### 手動乾跑

右端依序到索引 0、1，視窗和為 2、3；到 2 時和為 6，移去 2 後和為 4，長度 2；到 3 時和為 6，移去 1 後和為 5，視窗 [3,2] 長度仍為 2。

### 邊界與複雜度

- 邊界：空陣列回傳 0；limit 為負時也回傳 0；若允許負負載，此縮窗策略不保證最優，必須改方法。
- 複雜度：時間 O(n)，額外空間 O(1)：左右指標各最多走 n 步。

> [!TIP] 面試溝通
> 先說「負載非負」是不變量成立的條件，縮窗直到和合法才更新答案；不要把任意子序列誤當連續區間。
