## 為什麼要練這題

採購的價格表已由小到大排列 [1,3,4,7,9]；找兩筆加總 10，回傳價格對，找不到回傳 null。

> [!NOTE] 練習方式
> Schooling 目前不批改任意程式碼。下方是引導式實作與乾跑，頁面只對四選一自檢題提供即時回饋；請自行在本機執行程式並測試邊界。這裡的「Easy起步」是課程名稱，不代表與任何題庫的難度標籤等價。

## 先釐清規格，再寫解法

先口述輸入、輸出與失敗時的回傳值；有歧義就先詢問面試官。以下是此情境的一種 JavaScript 參考寫法，不是要求背誦的唯一答案。

```js
function sortedPair(a, target) {
  let left = 0, right = a.length - 1;
  while (left < right) {
    const sum = a[left] + a[right];
    if (sum === target) return [a[left], a[right]];
    if (sum < target) left++;
    else right--;
  }
  return null;
}
```

### 手動乾跑

1+9=10，立即回傳 [1,9]。若目標是 11，先算 1+9=10，左指標右移到 3；3+9=12，右指標左移到 7；3+7=10，回傳。

### 邊界與複雜度

- 邊界：空或單元素回傳 null；演算法必須先確認輸入已排序；重複價格可用不同索引，指標不相遇前不停止。
- 複雜度：時間 O(n)，額外空間 O(1)。

> 先向面試官確認有序前提；說明和太小時固定右端、提高左端才可能變大，和太大則反向。
