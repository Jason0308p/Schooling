## 為什麼要練這題

活動企劃有 [6,2,8,4] 四筆報價，要找兩個不同位置的報價相加為 10，回傳索引對；不存在回傳 null。

> [!NOTE] 練習方式
> Schooling 目前不批改任意程式碼。下方是引導式實作與乾跑，頁面只對四選一自檢題提供即時回饋；請自行在本機執行程式並測試邊界。這裡的「Easy起步」是課程名稱，不代表與任何題庫的難度標籤等價。

## 先釐清規格，再寫解法

先口述輸入、輸出與失敗時的回傳值；有歧義就先詢問面試官。以下是此情境的一種 JavaScript 參考寫法，不是要求背誦的唯一答案。

```js
function pairIndices(costs, target) {
  const index = new Map();
  for (let i = 0; i < costs.length; i++) {
    const need = target - costs[i];
    if (index.has(need)) return [index.get(need), i];
    if (!index.has(costs[i])) index.set(costs[i], i);
  }
  return null;
}
```

### 手動乾跑

i=0 記 6→0；i=1 記 2→1；i=2 的 8 需要 2，回傳 [1,2]。先查再存，避免同一筆配自己。

### 邊界與複雜度

- 邊界：[5]、目標 10 回傳 null；[5,5] 可回傳 [0,1]；若有多組答案，回傳掃描時最早找到的一組。
- 複雜度：時間 O(n)，額外空間 O(n)。

> [!TIP] 面試溝通
> 先問回傳值是金額還是索引、是否允許重複值；指出 Map 存的是已掃描索引，若輸入空陣列也會自然回傳 null。
