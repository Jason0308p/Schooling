## 為什麼要練這題

倉儲同事要找第一個重複掃描的箱號。輸入 [4,7,4,9]，回傳首次重複出現的箱號；若沒有則回傳 null。

> [!NOTE] 練習方式
> Schooling 目前不批改任意程式碼。下方是引導式實作與乾跑，頁面只對四選一自檢題提供即時回饋；請自行在本機執行程式並測試邊界。這裡的「Easy起步」是課程名稱，不代表與任何題庫的難度標籤等價。

## 先釐清規格，再寫解法

先口述輸入、輸出與失敗時的回傳值；有歧義就先詢問面試官。以下是此情境的一種 JavaScript 參考寫法，不是要求背誦的唯一答案。

```js
function firstRepeat(ids) {
  const seen = new Set();
  for (const id of ids) {
    if (seen.has(id)) return id;
    seen.add(id);
  }
  return null;
}
```

### 手動乾跑

依序看到 4、7 時加入集合；第三個 4 已存在，立刻回傳 4。這是依掃描順序的第一個重複，不是數值最小。

### 邊界與複雜度

- 邊界：空陣列回傳 null；負數、零都是合法箱號；不能先排序，因為會改變「首次」的語意。
- 複雜度：時間 O(n)，額外空間 O(n)。

> [!TIP] 面試溝通
> 面試時先確認「第一」指第二次出現的位置，接著說集合只記已讀過的值；用反例 [8,3,8,3] 確認語意。
