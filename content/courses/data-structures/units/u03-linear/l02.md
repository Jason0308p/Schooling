## 節點串起來，而非用索引跳過去

當你已經拿到清單中的某個節點，想在其後插入新節點，不必像陣列一樣搬動後續值；但若只知道「第 100 個」而只有 head，就得逐節點走過去。

```js
const first = { value: 'A', next: null };
const third = { value: 'C', next: null };
first.next = third;
const second = { value: 'B', next: null };
second.next = first.next; // 先接住 C
first.next = second;      // 再讓 A 指向 B
console.log(first.next.next.value); // C
```

若先改 `first.next = second` 才把 `second.next = first.next`，第二個節點會指回自己，原本 C 的入口就遺失。順序是正確性的關鍵。已持有插入位置時重接固定數目的指標為 O(1)；從 head 搜尋位置需要 O(n)。節點各有 next 指標，比只存值的陣列需要額外連結空間，也沒有 O(1) 隨機索引。

## 一次走訪與循環風險

```js
function toArray(head) {
  const out = [];
  for (let node = head; node !== null; node = node.next) {
    out.push(node.value);
  }
  return out;
}
console.log(toArray(first)); // ['A', 'B', 'C']
console.log(toArray(null)); // []
```

長度 n 且無環時，走訪 O(n) 時間；輸出陣列 O(n) 空間。若來源可能有環，這段會無限迴圈：可用 Set 記錄參照（O(n) 空間），或快慢指標以 O(1) 額外空間偵測環。不要在未定義資料是否有環前直接承諾一定終止。

> [!WARN] 刪除邊界
> 刪除頭節點要更新 head 本身；刪除尾節點時前驅的 next 要設為 null。若只持有欲刪節點但沒有前驅，單向鏈結串列不能一般性地 O(1) 刪掉尾節點。

## 面試口述

說清楚已給「節點參照」還是只給「值」：前者插入 O(1)，後者先找位置 O(n)。畫 A→C，在 A 後插 B，先令 B→C 再令 A→B；最後測空串列、只有一節點、插在尾端和疑似有環的輸入。
