## Set 表達「是否出現過」

活動報名名單可能有重複代碼。若只關心不同代碼的數量，Set 比把每個元素與既有元素逐一比較更直接。

```js
const ids = ['p1', 'p2', 'p1'];
const unique = new Set(ids);
console.log(unique.size); // 2
console.log(unique.has('p2')); // true
```

對 n 個基本型別值建 Set，通常按平均 O(n) 時間、O(k) 空間分析，k 是不同值數。若要保留重複次數，改用 Map；Set 只表示成員資格。物件同樣按參照辨識，兩個 `{id:1}` 不會自然去重。

## 不重複連續視窗

現在需求從「全域是否重複」改成「最長連續不重複片段」。維持 `[left, right]` 視窗與 Set；加入新元素前，只要它已存在，就從左端逐一移除直到不衝突。

```js
function longestDistinct(values) {
  const seen = new Set();
  let left = 0, best = 0;
  for (let right = 0; right < values.length; right++) {
    while (seen.has(values[right])) {
      seen.delete(values[left]);
      left++;
    }
    seen.add(values[right]);
    best = Math.max(best, right - left + 1);
  }
  return best;
}
console.log(longestDistinct(['a', 'b', 'a', 'c'])); // 3: b,a,c
console.log(longestDistinct([])); // 0
```

每個元素最多被加入一次、移除一次，因此雖然有內層 while，總時間在 Set 平均操作模型下是 O(n)，不是 O(n²)；空間最壞 O(n)。重要不變條件是每輪結束時視窗內沒有重複值，且 `seen` 恰好包含視窗元素。

> [!WARN] 用途邊界
> 若要處理使用者眼中的文字字形，先把字串轉成符合需求的分段陣列；直接 `split('')` 會拆開某些 Unicode 字元。若陣列含物件，須先指定依 ID 還是依參照判重。

## 面試口述

以 `['a','b','a','c']` 為例：遇到第二個 a，移除左端舊 a，再納入新 a；接著 c 使長度為 3。說明「左指標只往右，右指標只往右」，就能解釋為何巢狀迴圈仍是線性。最後用全相同、全不同、空陣列檢查。
