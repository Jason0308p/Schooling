## 樹讓關係有層次

組織權限、分類目錄或檔案夾常是樹：一個根節點，每個非根節點有一個父節點，沒有環。不要把「二元樹」直接等同「二元搜尋樹」；前者每節點最多兩個子節點，後者還要求值的相對大小規則。

```js
const root = {
  value: 'A',
  left: { value: 'B', left: { value: 'D', left: null, right: null }, right: null },
  right: { value: 'C', left: null, right: null },
};
```

## 用佇列逐層看

```js
function levels(root) {
  if (root === null) return [];
  const queue = [root], output = [];
  let head = 0;
  while (head < queue.length) {
    const width = queue.length - head;
    const row = [];
    for (let i = 0; i < width; i++) {
      const node = queue[head++];
      row.push(node.value);
      if (node.left !== null) queue.push(node.left);
      if (node.right !== null) queue.push(node.right);
    }
    output.push(row);
  }
  return output;
}
console.log(levels(root)); // [['A'], ['B', 'C'], ['D']]
```

每輪的 width 是當前層尚未處理的數量；若直接用會增長的 queue.length 作迴圈終點，下一層也會混進來。n 個節點各進出佇列一次，時間 O(n)；佇列與輸出最壞 O(n) 額外空間。空樹回傳空陣列。此範例假設每個節點明確有 left/right，且空子節點為 null；資料若用 undefined，判斷需調整。

## 高度決定搜尋承諾

平衡的二元搜尋樹高度約 O(log n)，依比較規則搜尋通常 O(log n)；若按已排序順序直接插入且沒有平衡機制，可能退化為長鏈，高度 O(n)，搜尋最壞 O(n)。層序走訪對任何形狀都 O(n)，但佇列尖峰與樹的最大寬度有關。

> [!WARN] 面試常見誤判
> 不可因為「是樹」就說所有操作 O(log n)。先說是否有排序不變條件、是否維持平衡、資料是否有重複值。

## 口頭推理

先畫 A 的兩個孩子 B、C 與 B 的孩子 D；隊列從 `[A]` 到 `[B,C]` 再到 `[D]`。解釋 width 快照如何切層，接著測空樹、單節點以及只有右孩子的退化樹。
