## 圖不一定有根，還可能繞回原點

服務依賴、交通站點、好友關係都可用圖表示。頂點是項目、邊是關係；無向邊要在兩端都記錄，有向邊則只記錄出邊。鄰接表適合儲存稀疏圖，空間 O(V+E)，其中 V 為頂點數、E 為邊數（無向圖每條邊會記錄兩次，常數倍不改階數）。

```js
const graph = new Map([
  ['A', ['B', 'C']],
  ['B', ['A', 'D']],
  ['C', ['A', 'D']],
  ['D', ['B', 'C']],
]);
function bfs(graph, start) {
  if (!graph.has(start)) return [];
  const seen = new Set([start]);
  const queue = [start], order = [];
  let head = 0;
  while (head < queue.length) {
    const node = queue[head++];
    order.push(node);
    for (const neighbor of graph.get(node) ?? []) {
      if (seen.has(neighbor)) continue;
      seen.add(neighbor); // 入隊時標記，避免重複入隊
      queue.push(neighbor);
    }
  }
  return order;
}
console.log(bfs(graph, 'A')); // ['A', 'B', 'C', 'D']
console.log(bfs(graph, 'X')); // []
```

BFS 用佇列按距離層逐步探索。在所有邊權重相同的前提下，第一次發現目標即得到最少邊數；若邊權不同，不能直接用一般 BFS 求最小總權重。DFS 使用遞迴或明確堆疊，適合探索連通性或回溯，但首次到達不保證無權圖的最短路徑。

## 成本與陷阱

用鄰接表與 seen 時，遍歷從起點可達的頂點和邊，時間 O(V+E) 上界、額外空間 O(V)（輸出、佇列、seen）。遇到環若不標記可能永遠走不完；若圖不連通，從 A 出發不會自動遍歷另一個分量。要遍歷全圖，需對每個尚未訪問的頂點再啟動一次。

> [!WARN] 頂點資料
> 範例預設所有鄰居都有 Map 紀錄，且標籤是穩定字串；資料可能有重複邊、缺漏端點或物件鍵時，先訂好清理與相等規則。

## 面試口述

畫三角環 A—B—C—A，說明在「入隊時」標記可防重複；接著指出另一個孤立頂點不會被這次走訪涵蓋。最後問邊是否有方向、是否有權重、是否要整圖或只要起點可達區域，才選 BFS、DFS 或其他演算法。
